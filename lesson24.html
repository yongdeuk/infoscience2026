    이진 트리와 이진 탐색 트리

    이진 트리는 자식이 최대 2개(왼쪽·오른쪽)인 트리입니다. 리스트에 순서대로 담으면 인덱스 계산만으로 가족 관계를 알 수 있습니다.

    찾는 노드계산
    부모 노드i // 2
    왼쪽 자식2 * i
    오른쪽 자식2 * i + 1
    이진 탐색 트리의 3가지 규칙 — ① 모든 노드는 서로 다른 값을 가진다 ② 왼쪽 서브 트리에는 그 노드보다 작은 값만 있다 ③ 오른쪽 서브 트리에는 그 노드보다 큰 값만 있다. 이 규칙은 모든 서브 트리에 재귀적으로 적용됩니다.

    데이터를 넣는 과정 — 8, 3, 5, 14, 2, 10 순서로 입력

    8  입력 → 루트가 된다
3  입력 → 8보다 작으므로 왼쪽
5  입력 → 8보다 작아 왼쪽, 3보다 크므로 3의 오른쪽
14 입력 → 8보다 크므로 오른쪽
2  입력 → 8보다 작아 왼쪽, 3보다 작으므로 3의 왼쪽
10 입력 → 8보다 커서 오른쪽, 14보다 작으므로 14의 왼쪽

bst = [0] * 30

def insert(idx, num):
    if bst[idx] == 0:
        bst[idx] = num
    elif num < bst[idx]:
        insert(idx * 2, num)
    else:
        insert(idx * 2 + 1, num)

    insert(1, v)

def count(num):
    idx, cnt = 1, 1
    while bst[idx] != num:
        if num < bst[idx]:
            idx = idx * 2
        else:
            idx = idx * 2 + 1
        cnt += 1
    return cnt

for x in [5, 2, 7, 12]:

    해설 — 7은 5보다 커서 오른쪽 8로, 8보다 작아서 8의 왼쪽 자식이 돼요.
