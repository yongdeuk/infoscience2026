1생각 열기

컴퓨터의 '내 문서' 폴더 안에는 '수업', '사진' 폴더가 있고, '수업' 안에는 또 '정보', '수학' 폴더가 있어요. 이 구조를 그림으로 그리면 어떤 모양이 될까요? 스택이나 큐처럼 한 줄로 늘어놓을 수 있을까요?

    교과서 · Ⅱ 2-1 트리 — 계층을 표현하는 구조

    학교 조직도, 폴더 구조처럼 위아래 관계가 있는 데이터를 담습니다.

    이 시간에 배울 내용

    계층이 있는 데이터는 어떻게 표현할까?

    • 트리가 무엇인지 알고, 트리의 구성 요소를 가리키는 말을 쓸 수 있어요.
    • 트리를 인접 행렬, 인접 리스트, 리스트로 저장할 수 있어요.
    • 이진 탐색 트리로 값을 빠르게 찾을 수 있어요.
    생활 속 이야기 · 내 사진은 어디에

    컴퓨터에서 소풍 사진을 찾아요. ‘내 문서’ 폴더 안에 ‘사진’ 폴더가 있고, 그 안에 ‘2026년’ 폴더, 그 안에 ‘소풍’ 폴더가 있어요. 맨 위 폴더 하나에서 시작해 아래로 가지를 치며 내려가요.

    스택과 큐는 데이터를 한 줄로 늘어놓았어요. 이렇게 가지를 치며 갈라지는 데이터는 어떻게 담을까요?

    트리에서 자주 쓰는 용어

    용어뜻
    노드 · 링크데이터를 저장하는 자리 · 노드를 잇는 선
    루트 노드최상위 노드. 트리에 하나만 존재한다
    부모 노드어떤 노드와 직접 연결된 위쪽 노드. 루트를 뺀 모든 노드는 부모가 하나씩 있다
    자식 노드어떤 노드와 직접 연결된 아래쪽 노드. 없을 수도, 여럿일 수도 있다
    형제 노드부모가 같은 노드끼리
    단말 노드자식이 없는 노드 (잎 노드)
    서브 트리어떤 노드를 루트로 삼는 트리. 모든 노드는 자신의 서브 트리를 이룬다
    레벨 · 높이루트에서 떨어진 단계 · 트리 전체의 최대 레벨
    차수한 노드가 가진 자식의 수
    데이터 구조의 체계 — 선형 구조에는 스택·큐가, 비선형 구조에는 트리·그래프가 속합니다. 트리를 ‘나무’라 부르는 이유는 루트를 위에 두고 뒤집어 놓으면 나무 모양이 되기 때문입니다.

    빈칸

    차수와 단말 노드 찾기

    본문 그림의 트리를 딕셔너리로 적었어요(키: 노드, 값: 자식 목록). 빈칸을 채워 각 노드의 차수(자식 수)를 출력하고, 단말 노드(자식이 없는 노드)를 모으세요.

    tree = {'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F', 'G'],
        'D': ['H', 'I'], 'E': [], 'F': [], 'G': [], 'H': [], 'I': []}

leaves = []
for node, kids in tree.items():
    print(node, '차수', ___)
    if ___:
        leaves.append(node)
print('단말 노드:', leaves)
    힌트

    차수는 자식 목록의 길이 len(kids)예요. 단말 노드는 그 길이가 0인 노드예요.

    정답 코드 보기
    tree = {'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F', 'G'],
        'D': ['H', 'I'], 'E': [], 'F': [], 'G': [], 'H': [], 'I': []}

leaves = []
for node, kids in tree.items():
    print(node, '차수', len(kids))
    if len(kids) == 0:
        leaves.append(node)
print('단말 노드:', leaves)
    고치기

    부모 노드 찾기 함수 고치기

    parent(x)는 x의 부모를 돌려줘야 해요. E의 부모는 B, H의 부모는 D, 루트 A는 '없음'이에요. 그런데 지금은 모두 '없음'이 나와요. 무엇이 문제일까요?

    tree = {'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F', 'G'],
        'D': ['H', 'I'], 'E': [], 'F': [], 'G': [], 'H': [], 'I': []}

def parent(x):
    for p, kids in tree.items():
        if x in kids:
            return p
        else:
            return '없음'

for x in ['E', 'H', 'A']:
    print(f'{x}의 부모: {parent(x)}')
    힌트

    else의 return이 반복문 안에 있어서 첫 노드 A만 보고 바로 끝나요. '없음'은 모든 노드를 다 살펴본 뒤, 반복문 밖에서 돌려줘야 해요.

    정답 코드 보기
    tree = {'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F', 'G'],
        'D': ['H', 'I'], 'E': [], 'F': [], 'G': [], 'H': [], 'I': []}

def parent(x):
    for p, kids in tree.items():
        if x in kids:
            return p
    return '없음'

for x in ['E', 'H', 'A']:
    print(f'{x}의 부모: {parent(x)}')
    생각

    내 주변의 트리 그려 보기

    학교 조직도, 컴퓨터 폴더, 가족 관계, 게임 기술 트리 중 하나를 골라 트리로 정리해 보세요. 루트 노드, 단말 노드 2개, 형제 노드 한 쌍을 표시하고, 노드 수와 링크 수가 'n개와 n−1개' 관계인지 확인해 보세요.

    4확인 문제

    Q1노드가 12개인 트리의 링크는 몇 개일까요?

    해설 — 루트를 뺀 모든 노드가 부모와 연결되는 링크를 정확히 하나씩 가지므로 링크는 n−1 = 11개예요.

    Q2트리에 대한 설명으로 옳지 않은 것은 무엇일까요?

    해설 — 루트를 뺀 모든 노드는 부모가 정확히 하나예요. 부모가 여럿이면 트리가 아니라 그래프가 돼요.
