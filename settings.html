학생 제출 · 모두의 생각 보드

구글 시트에 연결하면 차시 페이지에 선생님께 제출 버튼과 모두의 생각 보드가 나타나요. 비워 두면 둘 다 숨겨집니다.

연결하는 법 (처음 한 번, 5분)
  1. 구글 드라이브에서 새 구글 시트를 만들고 이름을 정합니다(예: 정보과학 제출).
  2. 시트 메뉴 확장 프로그램 → Apps Script를 엽니다.
  3. 있던 코드를 지우고, 저장소의 apps-script/Code.gs 내용을 붙여 넣은 뒤 저장합니다.
  4. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱을 고릅니다.
  5. 실행 사용자: 나, 액세스 권한이 있는 사용자: 모든 사용자로 두고 배포를 누른 뒤, 권한을 허용합니다.
  6. 나온 웹 앱 URL(…/exec)을 위 칸에 붙여 넣고 아래 저장하기를 합니다.

학생 이름·학번과 제출 내용은 선생님의 구글 시트에만 저장돼요. 보드에는 이름 없이 내용만 보입니다.

차시별 생각 열기 영상

차시 페이지의 생각 열기에서 바로 재생되는 유튜브 영상이에요. 유튜브 주소(youtube.com/watch?v=…, youtu.be/…, 공유 링크 모두 가능)를 붙여 넣으면 바뀌고, 칸을 비우면 그 차시는 영상 없이 나와요. 고친 뒤 아래 저장하기까지 해야 학생 화면에 반영돼요.

수행평가 채점 기준표

구분이 수행인 평가마다 채점 기준표를 넣을 수 있어요. 엑셀(xlsx)·CSV 파일을 올리거나, 한글·엑셀·구글 시트에서 표를 통째로 복사해 붙여 넣으면 됩니다. 첫 줄은 제목 줄로 읽고, 첫 열의 병합된 칸은 위 칸 값으로 채웁니다. 넣은 뒤 아래 저장하기까지 해야 학생 화면에 나와요.

저장하기

① GitHub에서 저장 추천

아래 버튼을 누르면 설정이 복사되고, 저장소의 settings.json 편집 창이 새 탭으로 열립니다.

  1. 편집 창 안을 누르고 Ctrl+A로 모두 고른 뒤 Ctrl+V로 붙여 넣습니다.
  2. 오른쪽 위 Commit changes… → 다시 Commit changes를 누릅니다.
  3. 1분쯤 뒤 배포가 끝나면 모든 학생 화면에 적용돼요.

GitHub에 저장소 주인 계정으로 로그인되어 있어야 합니다.

② 파일로 저장

settings.json을 내려받아 GitHub 저장소에서 같은 이름의 파일로 바꿔 올려도 됩니다(Add file → Upload files).
