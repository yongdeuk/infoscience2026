함수로 구현하는 스택 & 큐

우리 주변에서 스택(LIFO)처럼 동작하는 예와 큐(FIFO)처럼 동작하는 예를 하나씩 찾아, 파이썬 class로 직접 만들어 보는 활동입니다. 스택은 마지막에 넣은 것을 가장 먼저 꺼내는 구조, 큐는 먼저 넣은 것을 먼저 꺼내는 구조예요. 저장할 수 있는 최대 개수도 스스로 정하고, 꽉 찼을 때(오버플로우)와 텅 비었을 때(언더플로우) 어떻게 할지도 만들어야 합니다.

1

실생활 예시 찾기

스택은 “마지막에 넣은 걸 먼저 꺼내는” 상황, 큐는 “먼저 온 순서대로 처리하는” 상황을 나만의 예로 하나씩 정합니다.

2

class로 설계하기

넣기(push)·빼기(pop)·확인하기(peek)·비었는지 확인하기(isEmpty) 기능을 정하고, 꽉 찼을 때·비었을 때 어떻게 할지 계획을 세웁니다.

3

코드 작성 · 검증

설계한 대로 class를 코드로 완성하고, ▶ 실행 버튼으로 직접 돌려보며 결과를 확인합니다.

실생활 예시 참고 목록 보기
스택(LIFO)
  • 웹 브라우저 뒤로 가기
  • 되돌리기(Ctrl+Z) 기능
  • 쌓아놓은 책·접시 더미
  • 옷장에 쌓인 옷 꺼내 입기
  • 주차타워 출차 순서
  • 게임 이동·행동 취소
  • 최근 본 목록 최근 것부터 삭제
큐(FIFO)
  • 은행·병원 번호표 대기
  • 놀이기구 줄서기
  • 급식소 배식 줄
  • 프린터 인쇄 대기열
  • 온라인 티켓 예매 대기 순번
  • 콜센터 상담원 연결 대기
  • 세탁소·수선집 접수 순서

⚙ 구현 방식 — 교과서에서 배운 대로 class Stack: / class Queue:처럼 class로 직접 만드세요. collections.deque, queue 모듈처럼 파이썬에 이미 만들어진 도구를 가져다 쓰면 안 되고, 리스트를 저장 공간으로 삼아 push·pop·peek·isEmpty 동작을 내가 직접 코드로 써야 합니다.
