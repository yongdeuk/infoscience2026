DFS와 BFS — 같은 그래프, 다른 방문 순서

깊이 우선 탐색은 스택으로 끝까지 파고들고, 너비 우선 탐색은 큐로 가까운 곳부터 넓혀 갑니다. 한 단계씩 눌러 보며 스택·큐에 무엇이 들어가고 나오는지 지켜보세요. 노드를 누르면 시작 노드가 바뀝니다.

지금 방문 방문 끝 대기 중(스택·큐 안)

이웃 노드는 알파벳 순서로 살펴봅니다. DFS는 스택에 이웃을 역순으로 넣어 알파벳이 빠른 이웃부터 꺼내지도록 했습니다. 같은 그래프라도 방법과 시작 노드에 따라 방문 순서가 달라집니다.

BFS 구현 (큐)

from collections import deque

graph = {
    'A': ['B', 'C'], 'B': ['A', 'D', 'E'], 'C': ['A', 'F'],
    'D': ['B', 'G'], 'E': ['B', 'G', 'H'], 'F': ['C', 'H'],
    'G': ['D', 'E'], 'H': ['E', 'F'],
}

def bfs(start):
    visited = [start]
    queue = deque([start])
    while queue:
        node = queue.popleft()          # 먼저 들어온 노드부터
        for nxt in graph[node]:
            if nxt not in visited:
                visited.append(nxt)
                queue.append(nxt)
    return visited

print('BFS:', bfs('A'))

이진 탐색 트리 — 넣고, 찾고, 순회하기

값을 넣으면 루트부터 작으면 왼쪽, 크면 오른쪽으로 내려가 자리를 찾습니다. 찾을 때도 같은 길을 따라가므로 한 번 비교할 때마다 한쪽 서브 트리를 통째로 버립니다.

이진 탐색 트리 시뮬레이터

정렬된 순서로 넣기를 눌러 보세요. 1, 2, 3, …처럼 이미 정렬된 값을 넣으면 트리가 한쪽으로만 길어져 순차 탐색과 다를 바 없어집니다. 그래서 실제로는 균형을 맞추는 트리(AVL, 레드-블랙 트리)를 씁니다.

정렬 알고리즘 경주

같은 배열을 네 가지 방법으로 동시에 정렬합니다. 비교 횟수가 곧 걸리는 시간입니다. 배열 모양을 바꿔 가며 어떤 방법이 언제 유리한지 비교해 보세요.

직접 해 보기
버블 · 선택 · 삽입 · 퀵 정렬 동시 실행

버블·선택·삽입 정렬은 O(n²), 퀵 정렬은 평균 O(n log n)입니다. 단, 삽입 정렬은 거의 정렬된 배열에서 매우 빠르고, 첫 원소를 피벗으로 쓰는 퀵 정렬은 이미 정렬된 배열에서 O(n²)로 느려집니다. 색: ■ 비교 중, ■ 자리 확정.
