프로그래밍

효율적인 프로그래밍을 위한 함수와 재귀 구조의 활용법을 익혀 다양한 분야의 문제를 해결한다.

1-1 함수의 이해 1~2주차

여러 줄짜리 작업을 이름 하나로 묶어 두고, 필요할 때마다 불러 쓰는 장치가 함수입니다.

쉽게 말하면

로봇에게 “라면 끓여 줘”라고 한마디만 하면 되는 이유는, ‘물 550mL 끓이기 → 면과 수프 넣기 → 5분 끓이기 → 불 끄기 → 그릇에 담기’를 ‘라면 끓이기’라는 이름 하나로 묶어 두었기 때문입니다. 이 묶음이 함수이고, ‘라면 3개’, ‘계란 추가’처럼 바꿔 넣는 값이 매개 변수입니다.

함수의 구조

함수는 특정한 작업을 수행하도록 작성된 독립적인 코드 블록입니다. 파이썬이 미리 준비해 둔 내장 함수(print(), sum())와, 필요에 따라 직접 만드는 사용자 정의 함수가 있습니다.

def 함수명(매개 변수1, 매개 변수2, ... ):
    실행할 문장
    return 반환값
구성 요소설명필수 여부
함수명고유한 함수 이름필수
매개 변수인수를 전달받기 위해 사용하는 변수생략 가능
함수 본문기능을 실행하기 위한 명령어(들여쓰기로 구분)필수
반환값처리 결과를 호출한 쪽으로 되돌려주는 값생략 가능

호출과 반환의 흐름

def find_middle_number(a, b, c):
    numbers = [a, b, c]
    numbers.sort()
    return numbers[1]

print(find_middle_number(5, 7, 3))   # 5
print(find_middle_number(10, 20, 30))  # 20
return의 두 가지 역할 — ① 값을 반환한다 ② 함수를 즉시 종료한다. 값 없이 return만 쓰면 None을 반환하며, 그 아래 문장은 실행되지 않습니다.

지역 변수와 전역 변수

drink = 'coffee'          # 전역 변수

def print_global_drink():
    global drink          # 전역 변수를 참조하겠다는 선언
    drink = 'coke'        # 전역 변수의 값 자체가 바뀜
    print('음료:', drink)
핵심 포인트
  • 함수 = 특정 작업을 수행하는 독립적인 코드 블록. def로 정의하고 이름으로 호출한다.
  • 인수는 보내는 값, 매개 변수는 받는 변수. 개수가 맞아야 한다.
  • return은 값 반환 + 함수 종료. 생략하면 None.
  • 함수를 쓰는 이유 세 가지 — 가독성 · 재사용성 · 유지 보수 용이성. (클린 코드의 핵심 원칙)
  • 지역 변수는 함수가 끝나면 사라지고, 전역 변수는 프로그램이 끝날 때까지 남는다. 전역 변수는 꼭 필요할 때만.

1-2 함수의 활용 3~4주차

매개 변수를 더 유연하게 만들고, 여러 함수를 파일 단위로 묶어 모듈로 관리합니다.

기본값 매개 변수

값을 전달하지 않아도 되도록 미리 값을 준비해 둔 매개 변수입니다. 그래서 선택적 매개 변수라고도 합니다. 반드시 일반 매개 변수보다 뒤에 놓아야 합니다.

def apply_discount(prices, discount=0):
    for price in prices:
        sale = round(price * (1 - discount))
        print(f'정가 {price} → 판매가 {sale}원')

apply_discount([1000, 2000])        # 할인 없음(기본값 0)
apply_discount([1000, 2000], 0.3)   # 30% 할인

가변 인수 매개 변수

몇 개가 들어올지 모를 때 *를 붙입니다. 전달된 인수 전부를 하나의 튜플로 관리하며, 한 함수에 하나만, 그리고 맨 뒤에 놓습니다.

def order_drinks(*drinks):
    if not drinks:
        print('주문한 음료가 없습니다.'); return
    print(', '.join(drinks) + ' 주문이 완료되었습니다.')

order_drinks('콜라', '사이다', '커피')
order_drinks('녹차', '홍차')
order_drinks()

여러 개의 값 반환

return은 객체 하나만 반환하지만, 콤마로 나열하면 튜플에 담아 한 번에 돌려줍니다.

import math
g = 9.8

def free_fall(height):
    time = math.sqrt(2 * height / g)
    velocity = g * time
    return time, velocity      # 튜플로 묶여 반환

t, v = free_fall(50)

클래스와 객체

클래스는 객체를 만들기 위한 설계도, 객체는 그 설계도로 찍어낸 실물입니다. 객체가 가지는 데이터는 속성(변수), 객체가 하는 일은 메소드(함수)입니다.

class Robot:
    def __init__(self, name):     # 생성자 — 객체가 만들어질 때 실행
        self.name = name
        self.speed = 0
    def run(self):
        self.speed = 10
        print(f'{self.name}가 {self.speed}km/h로 달립니다.')

robot1 = Robot('로봇A')
robot1.run()

2-1 재귀 구조의 이해 5주차

큰 문제를 “같은 모양의 더 작은 문제”로 바꿔 가며 푸는 방식입니다.

쉽게 말하면

러시아 인형 마트료시카를 열면 똑같이 생긴 더 작은 인형이 나옵니다. 마지막 가장 작은 인형까지 다 열어야 끝나죠. 큰 문제 안에 같은 모양의 작은 문제가 들어 있는 구조 — 이것이 재귀 구조입니다.

def power(x, n):
    if n == 0:              # 기본 단계
        return 1
    else:                   # 재귀 단계
        return x * power(x, n - 1)

power(2, 5)   # 32

① 숫자의 자릿수 합

    
숫자를 마지막 자릿수와 나머지 자릿수로 쪼개면, 나머지 부분이 똑같은 모양의 작은 문제가 됩니다.

    
def digit_sum(n):
    if n < 10:                 # 기본 단계: 한 자리면 그대로
        return n
    return digit_sum(n // 10) + n % 10

digit_sum(7925)   # ((7+9)+2)+5 = 23

def hanoi_tower(n, source, target, spare):
    if n == 1:
        print('원반 1', source, '→', target); return
    hanoi_tower(n - 1, source, spare, target)   # 위 n-1개 → 보조
    print('원반', n, source, '→', target)        # 가장 큰 원반 → 목표
    hanoi_tower(n - 1, spare, target, source)   # 보조 n-1개 → 목표

hanoi_tower(3, 'A', 'C', 'B')


    
③ 폴더 안의 폴더 — 파일 찾기

    
폴더 안에 폴더가 들어 있는 구조 자체가 재귀입니다. 하위 폴더를 만나면 같은 함수를 그 폴더에 대해 다시 부르면 됩니다.

    
import os

def find_item(root_path, target):
    for item in os.listdir(root_path):
        item_path = os.path.join(root_path, item)
        if os.path.isdir(item_path):              # 하위 폴더면
            result = find_item(item_path, target) # 재귀적으로 탐색
            if result:
                return result
        elif item == target:
            return item_path
    return None
