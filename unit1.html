쉽게 말하면

로봇에게 “라면 끓여 줘”라고 한마디만 하면 되는 이유는, ‘물 550mL 끓이기 → 면과 수프 넣기 → 5분 끓이기 → 불 끄기 → 그릇에 담기’를 ‘라면 끓이기’라는 이름 하나로 묶어 두었기 때문입니다. 이 묶음이 함수이고, ‘라면 3개’, ‘계란 추가’처럼 바꿔 넣는 값이 매개 변수입니다.

함수는 특정한 작업을 수행하도록 작성된 독립적인 코드 블록입니다. 파이썬이 미리 준비해 둔 내장 함수(print(), sum())와, 필요에 따라 직접 만드는 사용자 정의 함수가 있습니다.

호출과 반환의 흐름

def find_middle_number(a, b, c):
    numbers = [a, b, c]
    numbers.sort()
    return numbers[1]

print(find_middle_number(5, 7, 3))   # 5
print(find_middle_number(10, 20, 30))  # 20
return의 두 가지 역할 — ① 값을 반환한다 ② 함수를 즉시 종료한다. 값 없이 return만 쓰면 None을 반환하며, 그 아래 문장은 실행되지 않습니다.

예제 — 회문 검사: 조건에 걸리면 return으로 즉시 빠져나온다

def reverse(s):
    if len(s) == 0:                     # ❶ 빈 문자열이면
        print('문자열이 비어 있습니다.')
        return                          #    값 없이 종료
    elif len(s) > 20:                   # ❷ 너무 길면
        print('문자열의 길이가 너무 깁니다.')
        return
    r = s[::-1]
    print(f'기존: {s}, 역순: {r}', end='')
    if s == r:
        print(' ==> 회문입니다.')
    else:
        print(' ==> 회문이 아닙니다.')

reverse('')       # 문자열이 비어 있습니다.
reverse('level')  # 기존: level, 역순: level ==> 회문입니다.
reverse('cat')    # 기존: cat, 역순: tac ==> 회문이 아닙니다.
reverse('Believe you can, and you are halfway there')  # 길이가 너무 깁니다.
회문이란 앞에서 읽으나 뒤에서 읽으나 같은 문자열입니다. s[::-1]은 문자열을 통째로 뒤집습니다. f-string은 f'…{변수}…' 형태로 값을 문자열에 끼워 넣는 방법으로, 가독성이 좋습니다.

④ 매개 변수와 반환값이 모두 있는 함수 — 두 점 사이의 거리

def get_dist(point1, point2):     # 매개 변수로 튜플을 받음
    x1, y1 = point1
    x2, y2 = point2
    return ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 0.5

print(get_dist((0, 0), (3, 4)))   # 5.0

지역 변수와 전역 변수

  • 인수는 보내는 값, 매개 변수는 받는 변수. 개수가 맞아야 한다.
  • return은 값 반환 + 함수 종료. 생략하면 None.
  • 함수를 쓰는 이유 세 가지 — 가독성 · 재사용성 · 유지 보수 용이성. (클린 코드의 핵심 원칙)
  • 지역 변수는 함수가 끝나면 사라지고, 전역 변수는 프로그램이 끝날 때까지 남는다. 전역 변수는 꼭 필요할 때만.

1-2 함수의 활용 3~4주차

매개 변수를 더 유연하게 만들고, 여러 함수를 파일 단위로 묶어 모듈로 관리합니다.

예제 — 요세푸스 문제: 매번 4번째 학생을 뽑아 발표 순서 정하기

def get_order(n, k):
    students = list(range(1, n + 1))
    index = 0
    order = []
    while len(students) > 1:
        index = (index + k - 1) % len(students)   # n명 중 k번째 선택
        order.append(students.pop(index))         # 기록하고 목록에서 제거
    order.append(students[0])                     # 마지막 1명
    return order

print('발표 순서:', get_order(12, 4))
# [4, 8, 12, 5, 10, 3, 11, 7, 6, 9, 2, 1]

def find_winner(votes):
    votes = votes.split()                                  # 문자열 → 리스트
    unique = set(votes)                                    # ❶ 집합으로 중복 제거
    counts = [(c, votes.count(c)) for c in unique]         # ❷ (후보, 득표수)
    results = dict(counts)                                 #    리스트 → 딕셔너리
    win = max(results, key=results.get)                    # ❸ 최다 득표 후보
    return win, results[win]                               # ❹

votes = 'A A C C B A D A D C B A D B C B A C A D'
winner, count = find_winner(votes)
print('당선자: 기호', winner)   # A
print('득표수:', count)         # 7

재귀 구조의 개념 — ‘방 청소하기’로 이해하기

거울을 마주 보고 놓으면 거울 속에 또 다른 거울이 반복해서 비칩니다. 이처럼 문제나 데이터가 자기 자신을 반복적으로 포함하는 형태가 재귀 구조입니다. 하위 문제가 원래 문제와 같은 구조를 가진다는 것이 핵심입니다.

‘방 청소하기’ 기본 패턴
1. 현재 청소할 방을 선택한다.
2. 방이 깨끗한지 확인한다.
3. 방이 깨끗하지 않으면 청소한다.
4. 더 이상 청소할 방이 없으면 작업을 종료한다.
5. 그렇지 않으면 다음 방으로 이동하여 1번 단계부터 다시 시작한다.

예제 — 방 목록을 재귀로 청소하기

def clean_house(rooms):
    if len(rooms) == 0:            # 기본 단계(종료 조건)
        print('모든 방이 깨끗합니다!')
        return
    else:                          # 재귀 단계(재귀 호출)
        current_room = rooms[0]
        print(current_room, '청소 중...')
        rooms.remove(current_room)  # 청소한 방을 목록에서 제거
        clean_house(rooms)          # 남은 목록으로 다시 호출

rooms = ['침실', '욕실', '주방', '거실']
clean_house(rooms)
# 침실 청소 중… → 욕실 → 주방 → 거실 → 모든 방이 깨끗합니다!

def reach_peak(n):
    if n <= 0:                 # 기본 단계(종료 조건)
        return
    else:                      # 재귀 단계(재귀 호출)

def countdown(n):
    if n == 0:                    # 기본 단계(종료 조건)

    else:
        print(n, end=' ')
        return countdown(n - 1)

def factorial(n):
    if n == 0 or n == 1:          # 기본 단계
        return 1
    else:
        return n * factorial(n - 1)

def fib(n):
    if n <= 1:
        return n
    prev, curr = 0, 1
    for _ in range(n - 1):
        temp = prev + curr    # 앞의 두 항을 더하고
        prev = curr           # 한 칸씩 밀어 준다
        curr = temp
    return curr

print(fib(7))   # 13

def fib(n):
    if n <= 1:                       # 기본 단계
        return n
    else:                            # 재귀 단계
        return fib(n - 1) + fib(n - 2)

def find_max(data):
    if not data:              # 데이터가 비어 있으면
        return None
    max = data[0]
    for num in data:
        if num > max:
            max = num
    return max

print(find_max([3, 5, 2, 9, 1]))   # 9

def gcd_recursive(a, b):
    if b == 0:                       # 기본 단계
        return a
    else:                            # 재귀 단계

def hanoi_tower(n, source, target, spare):
    if n == 1:
        print('원반 1', source, '→', target); return
    hanoi_tower(n - 1, source, spare, target)   # 위 n-1개 → 보조
    print('원반', n, source, '→', target)        # 가장 큰 원반 → 목표
    hanoi_tower(n - 1, spare, target, source)   # 보조 n-1개 → 목표

④ 계단 오르기 — 재귀 관계 찾기


    

    
한 번에 한 계단 또는 두 계단을 오를 수 있을 때, n개의 계단을 오르는 방법의 수를 구해 봅시다. 규칙은 ① 시작점은 0층이며 계단 수에 포함되지 않고 ② 마지막 계단은 반드시 밟아야 합니다.

    
n번째 계단에 도착하는 방법은 n−1번째에서 한 계단 오르거나, n−2번째에서 두 계단 오르는 두 가지뿐입니다. 그래서 관계식이 이렇게 나옵니다.

    
f(1) = 1        # 한 계단: (1)
f(2) = 2        # 두 계단: (1,1) (2)
f(n) = f(n-1) + f(n-2)

    
def count_ways(n):
    if n == 0:            # 모든 계단을 다 오른 상태
        return 1
    if n < 0:             # 계단을 넘어선 경우는 세지 않음
        return 0
    return count_ways(n - 1) + count_ways(n - 2)

print(count_ways(10))   # 89

import os

def find_item(root_path, target):
    for item in os.listdir(root_path):
        item_path = os.path.join(root_path, item)
        if os.path.isdir(item_path):              # 하위 폴더면
            result = find_item(item_path, target) # 재귀적으로 탐색
            if result:
                return result
        elif item == target:
            return item_path
    return None

import random

def make_answer():                       # 정답 수 정하기
    return random.randint(1, 100)

def is_valid(text):                      # 올바른 입력인지 검사
    return text.isdigit() and 1 <= int(text) <= 100

def check(guess, answer):                # 추측과 정답 견주기
    if guess == answer:
        return '정답'
    elif guess < answer:
        return '더 큰 수예요'
    else:
        return '더 작은 수예요'

def play(guesses, answer, tries=1):      # 재귀 함수로 게임 진행
    if not guesses:                      # 기본 단계: 추측이 다 떨어짐
        print(f'기회를 모두 썼어요. 정답은 {answer}이었어요.')
        return
    text = guesses[0]
    if not is_valid(text):
        print(f"'{text}'은(는) 올바른 입력이 아니에요. 1~100 사이의 수를 넣어 주세요.")
        play(guesses[1:], answer, tries)             # 횟수는 세지 않고 다음으로
        return
    result = check(int(text), answer)
    print(f'{tries}번째 시도 {text}: {result}')
    if result == '정답':
        print(f'축하해요! {tries}번 만에 맞혔어요.')
        return
    play(guesses[1:], answer, tries + 1)             # 재귀 단계: 남은 추측으로 다시

answer = make_answer()
play(input('추측할 수들: ').split(), answer)

문제 1 세 수 중 최댓값 기초 · 함수

        
세 정수를 매개 변수로 받아 가장 큰 값을 반환하는 함수 max_of_three(a, b, c)를 작성하시오. 단, 내장 함수 max()는 쓰지 않는다.

        
max_of_three(3, 9, 5)  →  9
max_of_three(-2, -7, -4)  →  -2

        
정답과 해설

          
기준값을 하나 정해 두고 나머지와 차례로 비교합니다. 첫 값을 최댓값으로 가정하는 것이 정석입니다.

          
def max_of_three(a, b, c):
    biggest = a                 # 일단 a가 가장 크다고 가정
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest

print(max_of_three(3, 9, 5))       # 9
print(max_of_three(-2, -7, -4))    # -2

문제 3 점수가 몇 개든 평균 내기 중급 · 가변 인수

        
점수를 개수 제한 없이 받아 평균을 반환하는 average(*scores)를 작성하시오. 점수가 하나도 없으면 0을 반환한다.

        
average(80, 90, 100)  →  90.0
average()             →  0

        
정답과 해설

          
*scores는 전달된 인수를 모두 튜플로 묶습니다. 빈 튜플일 때 len()이 0이 되어 0으로 나누는 오류가 나므로 먼저 걸러 줍니다.

          
def average(*scores):
    if not scores:              # 빈 튜플이면
        return 0
    return sum(scores) / len(scores)

print(average(80, 90, 100))   # 90.0
print(average())              # 0

문제 6 리스트의 합을 재귀로 중급 · 재귀

        
반복문 없이 재귀만으로 리스트 원소의 합을 구하는 rsum(nums)를 작성하시오.

        
rsum([1, 2, 3, 4, 5])  →  15

        
정답과 해설

          
“첫 원소 + 나머지 리스트의 합”으로 쪼갭니다. 리스트가 비면 합은 0 — 이것이 기본 단계입니다.

          
def rsum(nums):
    if not nums:                  # 기본 단계: 빈 리스트의 합은 0
        return 0
    return nums[0] + rsum(nums[1:])   # 재귀 단계

print(rsum([1, 2, 3, 4, 5]))      # 15

        

      


      

        
문제 7 최대공약수와 최소공배수 중급 · 재귀

        
유클리드 알고리즘을 재귀로 구현해 gcd(a, b)를 만들고, 이를 이용해 lcm(a, b)도 작성하시오.

        
gcd(48, 18)  →  6
lcm(48, 18)  →  144

        
정답과 해설

          
두 수의 곱은 최대공약수 × 최소공배수와 같습니다. 그래서 lcm은 gcd로 바로 구할 수 있습니다.

          
def gcd(a, b):
    if b == 0:                    # 기본 단계
        return a
    return gcd(b, a % b)          # 재귀 단계

def lcm(a, b):
    return a * b // gcd(a, b)

print(gcd(48, 18))    # 6
print(lcm(48, 18))    # 144

def moves(n):

문제 10 은행 계좌 클래스 심화 · 클래스

        
예금·출금·잔액 확인이 가능한 Account 클래스를 작성하시오. 잔액보다 많이 출금하려 하면 거절 메시지를 출력한다.

        
계좌 개설: 민서 / 잔액 0원
입금 10000 → 잔액 10000원
출금 30000 → 잔액이 부족합니다.
출금 3000  → 잔액 7000원

        
정답과 해설

          
속성은 __init__에서 초기화하고, 각 메소드의 첫 매개 변수는 self로 둡니다.

          
class Account:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
        print(f'계좌 개설: {owner} / 잔액 {balance}원')

    def deposit(self, amount):
        self.balance += amount
        print(f'입금 {amount} → 잔액 {self.balance}원')

    def withdraw(self, amount):
        if amount > self.balance:
            print(f'출금 {amount} → 잔액이 부족합니다.')
            return
        self.balance -= amount
        print(f'출금 {amount} → 잔액 {self.balance}원')

a = Account('민서')
a.deposit(10000)
a.withdraw(30000)
a.withdraw(3000)

마무리 단원 퀴즈
보기를 누르면 바로 채점되고 해설이 나옵니다. 가장 좋은 점수는 내 학습에 기록돼요.



  

    
Q1함수를 호출할 때 괄호 안에 넣어 실제로 전달하는 값을 무엇이라고 하나요?

    

    
해설 — 호출할 때 넣는 값이 인수, 정의할 때 괄호 안에 적어 그 값을 받는 변수가 매개 변수입니다.

  

  

    
Q2다음 코드의 실행 결과는?

    
def add(a, b=10):
    return a + b

print(add(5))

    

    
해설 — b를 생략했으므로 기본값 10이 쓰여 5 + 10 = 15입니다.

  

  

    
Q3다음 코드의 실행 결과는?

    
x = 1
def f():
    x = 5
    return x

f()
print(x)

    

    
해설 — 함수 안의 x = 5는 새 지역 변수를 만들 뿐 전역 변수 x는 바뀌지 않습니다. 전역 x를 바꾸려면 global x가 필요합니다.

  

  

    
Q4return이 없는 함수를 호출해 그 결과를 출력하면 무엇이 나오나요?

    

    
해설 — 반환값이 없는 함수는 자동으로 None을 돌려줍니다.

  

  

    
Q5다음 코드의 실행 결과는?

    
def total(*nums):
    return sum(nums)

print(total(1, 2, 3, 4))

    

    
해설 — *nums는 가변 인수로, 넘긴 값들을 튜플 (1, 2, 3, 4)로 받습니다. 합은 10입니다.

  

  

    
Q6클래스와 객체에 대한 설명으로 옳은 것은?

    

    
해설 — 클래스가 설계도이고 객체는 그 실체이며, 한 클래스로 여러 객체를 만들 수 있습니다. 생성자 __init__은 객체 생성 시 자동 실행되고, 메서드를 정의할 때는 self를 첫 매개 변수로 적어야 합니다.

  

  

    
Q7import random 후 1부터 6 사이 정수 하나를 무작위로 뽑는 코드는?

    

    
해설 — random.randint(a, b)는 a 이상 b 이하의 정수를 돌려줍니다. 양 끝을 모두 포함합니다.

  

  

    
Q8재귀 함수에 반드시 있어야 하는 것은?

    

    
해설 — 더 이상 자기 자신을 부르지 않는 종료 조건이 없으면 호출이 끝없이 쌓여 RecursionError가 납니다.

  

  

    
Q9다음 코드의 실행 결과는?

    
def f(n):
    if n == 0:
        return 0
    return n + f(n - 1)

print(f(4))

    

    
해설 — f(4) = 4 + f(3) = 4 + 3 + 2 + 1 + 0 = 10. 1부터 n까지의 합을 재귀로 구합니다.

  

  

    
Q10원판 4개짜리 하노이 탑을 옮기는 최소 이동 횟수는?

    

    
해설 — 최소 이동 횟수는 2ⁿ − 1입니다. 2⁴ − 1 = 15번.
