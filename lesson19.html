    힌트

    front는 인덱스 0이에요. 넣기는 append, 빼기는 pop(0), 보기는 que[0]이에요.

    정답 코드 보기
    class Queue:
    def __init__(self):
        self.que = []
    def isEmpty(self):
        return len(self.que) == 0
    def enqueue(self, data):
        self.que.append(data)
    def dequeue(self):
        if not self.isEmpty():
            return self.que.pop(0)
    def peek(self):
        if not self.isEmpty():
            return self.que[0]

q = Queue()
for ch in ['A', 'B', 'C']:
    q.enqueue(ch)
print(q.peek())
print(q.dequeue())
print(q.dequeue())
print(q.isEmpty())
    고치기

    스택 vs 큐 비교 코드 고치기

    같은 순서로 A, B, C, D를 넣었는데 큐와 스택이 똑같이 D C B A를 내놓아요. 큐는 A B C D가 나와야 해요. 한 줄을 고치세요.

    queue = []
stack = []
for ch in 'ABCD':
    queue.append(ch)
    stack.append(ch)

q_out = []
s_out = []
while queue:
    q_out.append(queue.pop())
while stack:
    s_out.append(stack.pop())
print('큐:', ' '.join(q_out))
print('스택:', ' '.join(s_out))
    힌트

    큐는 가장 먼저 넣은 것, 즉 맨 앞(인덱스 0)에서 꺼내야 해요.

    정답 코드 보기
    queue = []
stack = []
for ch in 'ABCD':
    queue.append(ch)
    stack.append(ch)

q_out = []
s_out = []
while queue:
    q_out.append(queue.pop(0))
while stack:
    s_out.append(stack.pop())
print('큐:', ' '.join(q_out))
print('스택:', ' '.join(s_out))
    만들기

    놀이기구 탑승 시뮬레이션

    놀이기구는 한 번에 최대 2명씩 태워요. 줄(큐)이 빌 때까지 앞에서부터 2명씩 꺼내 1회차 탑승: 민수, 지아처럼 출력하세요. 마지막 회차에는 1명만 탈 수도 있어요.

    line = ['민수', '지아', '하준', '서연', '도윤']
turn = 0
while line:
    turn += 1
    riders = []
    for _ in range(2):        # 최대 2명
        if ___:               # 줄에 사람이 남아 있으면
            riders.append(___)   # 맨 앞 사람을 꺼내 태우기
    print(f'{turn}회차 탑승:', ', '.join(riders))
    힌트

    빈 리스트는 거짓이라 if line:으로 사람이 남았는지 알 수 있어요. 맨 앞 사람은 line.pop(0)으로 꺼내요. 꺼내지 않으면 줄이 줄지 않아 끝나지 않아요!

    정답 코드 보기
    line = ['민수', '지아', '하준', '서연', '도윤']
turn = 0
while line:
    turn += 1
    riders = []
    for _ in range(2):
        if line:
            riders.append(line.pop(0))
    print(f'{turn}회차 탑승:', ', '.join(riders))

    Q1큐에 대한 설명으로 옳은 것은 무엇일까요?

    Q2파이썬 리스트 q를 큐로 쓸 때, 데이터를 꺼내는 코드로 알맞은 것은 무엇일까요?
