    교과서 · Ⅱ 2-1 트리 — 계층을 표현하는 구조

    트리를 컴퓨터에 저장하는 두 가지 방법

    방법저장 방식장점단점
    인접 행렬n×n 2차원 리스트에 연결이 있으면 1연결 여부를 바로 확인빈칸이 많아 메모리 낭비
    인접 리스트노드마다 연결된 노드만 리스트로 저장메모리 절약특정 연결 확인이 상대적으로 느림

    인접 행렬로 트리 저장하기

    n = int(input('노드 개수: '))
m = n - 1                                    # 트리의 링크 수는 항상 n-1
am =    # n × n 2차원 리스트

print(f'링크 정보를 부모 노드와 자식 노드 순서로 {m}개 입력하세요.')
for i in range(m):
    e1, e2 = input().split()                 # 노드 이름은 대문자로, 한 칸 띄워 입력
    am[][ord(e2) - ord('A')] = 1

for i in range(n):                           # 저장된 값 출력
    for j in range(n):
        print(am[i][j], end=' ')
    print()
    ord('A')는 문자 A의 정숫값(65)을 돌려줍니다. ord(문자) - ord('A')로 A→0, B→1 … 처럼 이름을 인덱스로 바꿉니다. split()은 공백을 기준으로 문자열을 나눕니다.

    인접 리스트로 트리 저장하기

    n = int(input('노드 개수: '))
m = n - 1
al = [[0] for _ in range(n)]                 # 각 리스트의 첫 칸은 부모 노드 자리

print(f'링크 정보를 부모 노드와 자식 노드 순서로 {m}개 입력하세요.')
for i in range(m):
    e1, e2 = input().split()
    al[ord(e1) - ord('A')]        # 부모의 리스트에 자식 추가
    al[ord(e2) - ord('A')]           # 자식의 리스트 첫 칸에 부모 저장

vertex = 'A'
for vlist in al:
    print(f'[{vertex}]: ', end=' ')
    for v in vlist:
        print(v, end=' ')
    print()
    vertex = chr(ord(vertex) + 1)            # 다음 알파벳으로
    루트 노드는 부모가 없으므로 첫 칸에 0이 남습니다. 예를 들어 A → 0 B C D는 “A는 부모가 없고 자식이 B·C·D”라는 뜻입니다.

    links = [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'E'), ('C', 'F')]
n = 6
am = [[0 for _ in range(n)] for _ in range(n)]
for e1, e2 in links:
    am[___][___] = 1

    힌트

    행은 부모 e1, 열은 자식 e2예요. ord(e1) - ord('A')처럼 바꿔요.

    정답 코드 보기
    links = [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'E'), ('C', 'F')]
n = 6
am = [[0 for _ in range(n)] for _ in range(n)]
for e1, e2 in links:
    am[ord(e1) - ord('A')][ord(e2) - ord('A')] = 1
for row in am:
    for x in row:
        print(x, end=' ')
    print()
    고치기

    모든 노드가 똑같아지는 인접 리스트

    인접 리스트를 만들었는데 모든 노드의 리스트가 똑같이 이상하게 나와요. [A]는 0 B C D, [E]는 B(부모 B, 자식 없음)여야 해요. 리스트를 만드는 한 줄이 문제예요.

    links = [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'E'), ('C', 'F')]
n = 6
al = [[0]] * n
for e1, e2 in links:
    al[ord(e1) - ord('A')].append(e2)
    al[ord(e2) - ord('A')][0] = e1
for i in range(n):
    print(f'[{chr(i + 65)}]:', end=' ')
    for v in al[i]:
        print(v, end=' ')
    print()
    힌트

    [[0]] * n은 리스트 하나를 n번 가리키는 것이라 한 곳을 바꾸면 전부 바뀌어요. [[0] for _ in range(n)]로 각각 새로 만들어야 해요.

    정답 코드 보기
    links = [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'E'), ('C', 'F')]
n = 6
al = [[0] for _ in range(n)]
for e1, e2 in links:
    al[ord(e1) - ord('A')].append(e2)
    al[ord(e2) - ord('A')][0] = e1
for i in range(n):
    print(f'[{chr(i + 65)}]:', end=' ')
    for v in al[i]:
        print(v, end=' ')
    print()
    만들기

    두 방법의 칸 수 비교하기

    같은 트리를 두 가지로 저장하고, 쓴 칸 수를 비교하세요. 인접 행렬은 전체 칸 수와 1이 적힌 칸 수를, 인접 리스트는 모든 리스트 길이의 합을 출력해요. 예: 인접 행렬: 36칸 중 1은 5칸 / 인접 리스트: 11칸

    links = [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'E'), ('C', 'F')]
n = 6
am = [[0 for _ in range(n)] for _ in range(n)]
al = [[0] for _ in range(n)]
for e1, e2 in links:
    p, c = ord(e1) - ord('A'), ord(e2) - ord('A')
    # am과 al에 링크를 저장하세요

ones = 0         # am에서 1인 칸 수를 세세요
total = 0        # al의 모든 리스트 길이를 더하세요

print(f'인접 행렬: {n * n}칸 중 1은 {ones}칸')
print(f'인접 리스트: {total}칸')
    힌트

    am[p][c] = 1, al[p].append(e2), al[c][0] = e1로 저장해요. 1의 개수는 sum(row)를, 칸 수는 len(lst)를 반복문으로 더하면 돼요.

    정답 코드 보기
    links = [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'E'), ('C', 'F')]
n = 6
am = [[0 for _ in range(n)] for _ in range(n)]
al = [[0] for _ in range(n)]
for e1, e2 in links:
    p, c = ord(e1) - ord('A'), ord(e2) - ord('A')
    am[p][c] = 1
    al[p].append(e2)
    al[c][0] = e1

ones = 0
for row in am:
    ones += sum(row)
total = 0
for lst in al:
    total += len(lst)

print(f'인접 행렬: {n * n}칸 중 1은 {ones}칸')
print(f'인접 리스트: {total}칸')

    4확인 문제

    Q1노드 B를 인접 행렬의 인덱스로 바꾸는 식 ord('B') - ord('A')의 값은 무엇일까요?

    해설 — ord('A')=65, ord('B')=66이라 66−65=1이에요. A가 0번이니 B는 1번 행·열이에요.

    Q2노드가 1000개인 트리를 저장할 때 인접 리스트가 인접 행렬보다 유리한 점은 무엇일까요?

    해설 — 인접 행렬은 1000×1000=100만 칸이 필요하지만 링크는 999개뿐이라 대부분 0이에요. 인접 리스트는 링크만 저장해요.
