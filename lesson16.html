1생각 열기

책상 위에 문제집을 5권 쌓아 두었어요. 맨 아래 수학 문제집을 꺼내려면 어떻게 해야 할까요? 그리고 가장 쉽게 꺼낼 수 있는 책은 어느 것일까요?

    코드 아래 💡 코드 설명을 펼쳐 보고, 빈칸이 있으면 채운 뒤 실행해 보세요.

    교과서 · Ⅱ 1-1 스택 — 나중에 넣은 것이 먼저 나온다

    한쪽 끝만 열려 있어서, 넣고 빼는 일이 모두 그 한 곳(top)에서만 일어납니다.

    이 시간에 배울 내용

    데이터를 차례로 쌓아 두었다가 거꾸로 꺼내야 할 때는 어떻게 할까?

    • 스택이 무엇인지 알고, 스택의 네 가지 연산을 설명할 수 있어요.
    • 파이썬 리스트로 스택을 만들 수 있어요.
    • 스택으로 문자열 뒤집기, 회문 검사, 괄호 검사 문제를 풀 수 있어요.
    생활 속 이야기 · 공항의 짐가방

    여행 가방에 책, 옷, 보조 배터리, 세면도구를 차례로 넣었어요. 공항에서 줄을 서 있는데, 보조 배터리는 비행기에 들고 타야 한다는 것이 생각났어요. 가방을 열어 보니 보조 배터리는 저 아래에 있어요.

    보조 배터리를 꺼내려면 어떻게 해야 할까요? 맨 위의 세면도구부터 하나씩 꺼내야 해요. 가장 나중에 넣은 것이 가장 먼저 나와요.

    쉽게 말하면

    접시에 쌓아 올린 핫케이크. 새로 구운 것은 맨 위에 올리고, 먹을 때도 맨 위부터 집습니다. 중간에서 빼낼 수는 없죠. 이것이 후입 선출(LIFO)입니다.

    Stack (LIFO)

    값을 입력하고 push를 눌러 보세요. 비워 두면 A, B, C… 순으로 자동 입력됩니다.

    꺼낸 순서: (없음)

    A → B → C 순서로 넣고 계속 pop 해 보세요. C → B → A, 넣은 것의 정반대 순서로 나옵니다.

    왜 리스트의 뒤쪽을 쓸까? 앞쪽에서 넣고 빼면 나머지 데이터가 전부 한 칸씩 밀려야 합니다. 뒤쪽은 그런 이동이 없어 훨씬 빠릅니다.

    전체 동작 확인

    s = Stack()
s.push('사과')
s.push('수박')
print(s.peek())   # 수박  ← 확인만, 삭제 안 함
s.push('포도')    # ['사과', '수박', '포도']
print(s.pop())    # 포도
print(s.pop())    # 수박
print(s.pop())    # 사과
    ADT(추상 자료형)란 데이터 구조가 어떻게 동작해야 하는지를 구현 방법과 분리해 정의한 것입니다. 스택의 ADT는 push(i) 추가 · pop() 삭제 · isEmpty() 공백 검사 · peek() 확인 네 가지입니다.

    Stack 클래스의 빈칸 세 곳을 채워 push는 맨 위에 넣고, pop은 맨 위를 꺼내고, peek은 맨 위를 보기만 하게 만드세요.

    def push(self, data):
        self.stack.___(data)
    def pop(self):
        if not self.isEmpty():
            return self.stack.___()
    def peek(self):
        if not self.isEmpty():
            return self.stack[___]

s = Stack()
s.push(1)
s.push(2)
s.push(3)
print(s.peek())
print(s.pop())
print(s.pop())
print(s.isEmpty())
    힌트

    리스트 맨 뒤가 top이에요. 맨 뒤에 붙이기는 append, 맨 뒤 꺼내기는 pop(), 맨 뒤 칸 인덱스는 -1이에요.

    정답 코드 보기
    class Stack:
    def __init__(self):
        self.stack = []
    def isEmpty(self):
        return len(self.stack) == 0
    def push(self, data):
        self.stack.append(data)
    def pop(self):
        if not self.isEmpty():
            return self.stack.pop()
    def peek(self):
        if not self.isEmpty():
            return self.stack[-1]

s = Stack()
s.push(1)
s.push(2)
s.push(3)
print(s.peek())
print(s.pop())
print(s.pop())
print(s.isEmpty())
    고치기

    큐처럼 동작하는 스택 고치기

    A, B, C를 넣고 세 번 꺼냈더니 A B C가 나와요. 스택이라면 C B A가 나와야 해요. 잘못된 한 줄을 찾아 고치세요.

    class Stack:
    def __init__(self):
        self.stack = []
    def isEmpty(self):
        return len(self.stack) == 0
    def push(self, data):
        self.stack.append(data)
    def pop(self):
        if not self.isEmpty():
            return self.stack.pop(0)

s = Stack()
for ch in ['A', 'B', 'C']:
    s.push(ch)
print(s.pop(), s.pop(), s.pop())
    힌트

    pop(0)은 리스트 맨 앞(가장 먼저 넣은 것)을 꺼내요. top은 맨 뒤예요.

    size는 len(self.stack)을 돌려주면 돼요. pop에는 if 블록 밖에 return '비어 있음'을 추가하세요.

    class Stack:

    4확인 문제

    Q1스택에 A, B, C, D를 차례로 push한 뒤 pop을 두 번 하면, 두 번째로 꺼낸 값은 무엇일까요?

    해설 — 첫 pop은 맨 위 D, 두 번째 pop은 그다음 C예요. 나중에 넣은 것이 먼저 나오는 LIFO예요.

    Q2pop()과 peek()의 차이로 옳은 것은 무엇일까요?

    해설 — 둘 다 top의 값을 돌려주지만, pop()만 그 값을 스택에서 지워요.
