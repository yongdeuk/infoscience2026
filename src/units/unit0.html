0-0 실습 환경 — Programiz 온라인 컴파일러 1주차

이 수업에서는 설치나 로그인 없이 브라우저에서 바로 파이썬을 실행하는 Programiz 온라인 컴파일러를 씁니다. 이 사이트의 예제는 코드 아래 ▶ 실행으로도 돌려 볼 수 있습니다.

  1. 열기 — programiz.com 파이썬 온라인 컴파일러를 엽니다. 예제 아래 Programiz에서 실행 버튼을 누르면 코드가 복사되고 바로 열립니다.
  2. 붙여넣기 — 왼쪽 편집 창(main.py)을 누르고 Ctrl+A로 예시 코드를 모두 선택한 뒤 Ctrl+V로 붙여넣습니다.
  3. 실행 — 파란 Run 버튼을 누르면 오른쪽 Output 창에 결과가 나옵니다.
  4. 입력 — input()이 있으면 Output 창을 눌러 값을 입력하고 Enter를 누릅니다.
  5. 보관 — Programiz는 코드를 저장하지 않습니다. 직접 짠 코드는 복사해서 학습지나 내 학습 노트에 옮겨 둡니다.
교과서에 나오는 다른 환경 — 교과서는 구글 코랩(Colab)과 설치형 프로그램 토니(Thonny)도 소개합니다. 집에서 파이썬을 설치해 쓰고 싶다면 thonny.org에서 내려받을 수 있습니다. 수업 시간에는 Programiz로 통일합니다.

0-1 변수와 출력

값에 이름을 붙여 저장하고, print()로 원하는 모양으로 보여 주는 방법입니다.

예제 1-1

슈팅 게임에서 플레이어 이름은 'Superman', 현재 점수는 72.5점입니다. 변수에 저장한 뒤 출력해 봅시다.

player = 'Superman'
score = 72.5
print(player, score)
해설 — 변수는 프로그램이 실행되는 동안 값이 바뀔 수 있는 이름표입니다. 값을 넣을 때는 대입 연산자 =를 쓰고, 문자열은 앞뒤에 따옴표를 붙입니다(교과서는 작은따옴표 사용).

예제 1-2

저장된 값을 '/'로 구분하고, 마지막에 '***'를 붙여 출력해 봅시다.

player = 'Superman'
score = 72.5
print(player, score, sep='/', end='***')
해설 — sep는 값 사이에 넣을 구분자(기본값은 공백), end는 출력이 끝난 뒤 붙일 문자(기본값은 줄 바꿈 \n)입니다.

예제 1-3

f 문자열로 점수를 소수점 둘째 자리까지 출력해 봅시다.

player = 'Superman'
score = 72.5
print(f'Player: {player}, Score: {score:.2f}')
해설 — 문자열 앞에 f를 붙이면 중괄호 안에 변수를 바로 넣을 수 있습니다. :.2f는 소수점 아래 둘째 자리까지 나타내는 형식입니다.

0-2 자료형

파이썬은 값에 따라 자료형을 자동으로 정합니다. type()으로 확인하고, 필요하면 바꿀 수 있습니다.

예제 2-1

변수들의 자료형을 type()으로 확인해 봅시다.

subject = '정보과학'
cnt = 25
avg = 99.5
isPass = True
print('subject의 타입:', type(subject))
print('cnt의 타입:', type(cnt))
print('avg의 타입:', type(avg))
print('isPass의 타입:', type(isPass))
해설 — 주요 자료형은 str(문자열), int(정수), float(실수), bool(논리형)입니다. 여러 값을 담는 list, tuple, dict, set도 있습니다.

예제 2-2

변수를 차례로 정수, 실수, 문자열로 바꿔 봅시다(형 변환).

a, b, c = '1', '2.5', 3
print('==== Before ====')
print('a의 타입:', type(a))
print('b의 타입:', type(b))
print('c의 타입:', type(c))
a, b, c = int(a), float(b), str(c)
print('==== After ====')
print('a의 타입:', type(a))
print('b의 타입:', type(b))
print('c의 타입:', type(c))
해설 — 형 변환은 값을 다른 자료형으로 바꾸는 것입니다. int(), float(), str(), bool()을 씁니다.

예제 2-3

참·거짓 값과 비교 결과의 자료형을 출력해 봅시다.

a = True
b = False
print(a, type(a))
print(b, type(b))
print(10 < 20, type(10 < 20))
print(20 < 10, type(20 < 10))
해설 — bool은 조건이 참인지 거짓인지 판단할 때 쓰입니다. 비교 연산의 결과도 bool입니다.

0-3 입력

input()은 사용자가 입력한 값을 받아 옵니다. 받은 값은 항상 문자열이라는 점이 핵심입니다.

예제 3-1

삼각형의 밑변과 높이를 입력받아 봅시다. (입력: 5, 7)

base = input()
height = input()
print(f'밑변: {base}, 높이: {height}')
print(type(base), type(height))
해설 — input()은 사용자가 값을 입력하고 Enter를 누를 때까지 기다렸다가, 그 값을 문자열로 돌려줍니다.

예제 3-2

안내 문구를 보여 주고, 실수로 바꿔 넓이를 구해 봅시다. (입력: 5, 7)

base = float(input('밑변 입력: '))
height = float(input('높이 입력: '))
area = 0.5 * base * height
print(f'넓이: {area:.2f}')
해설 — 괄호 안의 문구를 프롬프트라고 합니다. 계산하려면 int()나 float()로 형 변환해야 합니다.

예제 3-3

밑변과 높이를 한 줄에 함께 입력받아 봅시다. (입력: 5 7)

m = '밑변과 높이 입력: '
base, height = map(float, input(m).split())
area = 0.5 * base * height
print(f'넓이: {area:.2f}')
해설 — split()은 공백을 기준으로 입력을 나누고, map(float, …)은 나뉜 값 모두에 float를 적용합니다.

0-4 연산자

계산하고, 몫과 나머지를 구하고, 조건을 이어 붙이는 기호들입니다.

예제 4-1

x가 4일 때 (x³ + 1) / (x − 2)를 계산해 봅시다.

x = 4
print((x ** 3 + 1) / (x - 2))
해설 — 곱하기는 *, 나누기는 /(결과는 실수), 거듭제곱은 **입니다. 괄호로 계산 순서를 정할 수 있습니다.

예제 4-2

세 자리 수를 입력받아 각 자릿수를 출력해 봅시다. (입력: 357)

num = int(input('세 자리 숫자 입력: '))
x = num // 100
y = (num % 100) // 10
z = num % 10
print(f'백의 자리: {x}')
print(f'십의 자리: {y}')
print(f'일의 자리: {z}')
해설 — 몫은 //, 나머지는 %로 구합니다. 이 방법은 Ⅰ단원의 ‘자릿수 합’ 재귀 함수에서 다시 씁니다.

예제 4-3

x가 셋 중 가장 크면 True를 출력해 봅시다.

x, y, z = 50, 20, 30
print(x > y and x > z)
print(x < y or x < z)
해설 — and는 둘 다 참일 때, or는 하나만 참이어도 True입니다. not은 참·거짓을 뒤집습니다. 비교 연산이 논리 연산보다 먼저 계산됩니다.

0-5 조건문

조건이 참일 때만 실행할 코드를 정합니다. 들여쓰기로 블록을 구분합니다.

예제 5-1

입력한 정수가 7의 배수이면 메시지를 출력해 봅시다. (입력: 14)

num = int(input())
if num % 7 == 0:
    print('7의 배수입니다.')
해설 — if 문은 조건식이 True일 때만 블록을 실행합니다. 같은지 비교할 때는 ==(등호 두 개)를 씁니다.

예제 5-2

문장에 'Stay'가 들어 있는지, 몇 번 나오는지 알아봅시다.

a = 'Stay Hungry, Stay Foolish.'
if 'Stay' in a:
    print('Stay가 포함되어 있습니다.')
    print(a.count('Stay'))
else:
    print('Stay가 포함되어 있지 않습니다.')
해설 — '문구' in a는 문자열 a에 문구가 있으면 True입니다. a.count()는 등장 횟수를 셉니다.

예제 5-3

세 정수를 입력받아 가장 큰 값을 출력해 봅시다. (입력: 3 7 5)

a, b, c = map(int, input().split())
if a > b and a > c:
    print(a)
elif b > c:
    print(b)
else:
    print(c)
해설 — elif는 ‘else if’의 줄임말로 여러 번 쓸 수 있습니다. else는 모든 조건이 거짓일 때 실행되며 생략할 수 있습니다.

0-6 반복문

같은 일을 여러 번 할 때 씁니다. 조건이 참인 동안 도는 while, 차례로 꺼내며 도는 for가 있습니다.

예제 6-1

입력값의 제곱을 반복해서 출력하고, 0을 넣으면 끝내 봅시다. (입력: 5, 7, 0)

while True:
    num = int(input('숫자 입력(0: 종료) '))
    if num == 0:
        break
    print(f'{num}의 제곱은 {num ** 2}')
해설 — while True는 끝없이 반복하고, break를 만나면 즉시 반복을 빠져나옵니다.

예제 6-2

문자열의 글자마다 뒤에 '/'를 붙여 출력해 봅시다.

a = '정보과학'
for i in a:
    print(i, end='/')
해설 — for 문은 문자열·리스트 같은 시퀀스의 원소를 하나씩 꺼내 반복합니다.

예제 6-3

1부터 10까지의 홀수와 짝수를 출력해 봅시다.

for i in range(1, 10, 2):
    print(i, end=' ')
print()
for i in range(0, 10, 2):
    print(i, end=' ')
해설 — range(start, stop, step)은 start부터 stop 바로 전까지 step씩 건너뛴 수를 만듭니다. start를 생략하면 0, step을 생략하면 1입니다.

0-7 리스트

여러 값을 순서대로 담는 그릇입니다. 스택·큐를 만들 때도 리스트를 씁니다.

예제 7-1

요일 리스트를 만들고 '월', '수', '일'을 꺼내 봅시다.

days = ['월', '화', '수', '목', '금', '토', '일']
print(days)
print(days[0])
print(days[2])
print(days[-1])
해설 — 인덱스는 0부터 시작하고, 마지막 원소는 -1로 꺼낼 수 있습니다.

예제 7-2

두 리스트를 이어 붙이고 세 번 반복해 봅시다.

a = [1, 2]
b = [5, 7]
print((a + b) * 3)
해설 — 리스트끼리 더하면 이어 붙이고, 정수를 곱하면 그만큼 반복합니다.

예제 7-3

슬라이싱으로 리스트의 일부분을 꺼내 봅시다.

a = [1, 2, 3, 4, 5, 6, 7]
print(a[:2])
print(a[5:])
print(a[:5:2])
print(a[4:1:-1])
print(a[::-1])
해설 — [start:stop:step]에서 stop 위치는 포함하지 않습니다. [::-1]은 전체를 거꾸로 뒤집습니다.

예제 7-4

원소를 추가·정렬·뒤집기·제거하며 길이와 내용을 출력해 봅시다.

a = ['A', 'C']
print(len(a), a)
a.append('B')
print(len(a), a)
a.sort()
print(len(a), a)
a.reverse()
print(len(a), a)
a.remove('C')
print(len(a), a)
해설 — len() 개수, append(x) 끝에 추가, sort() 오름차순 정렬(reverse=True면 내림차순), reverse() 뒤집기, remove(x) 처음 나오는 x 삭제.

0-8 튜플

리스트처럼 순서가 있지만, 한번 만들면 값을 바꿀 수 없는 그릇입니다.

예제 8-1

학번과 이름으로 된 튜플 두 개를 다시 튜플로 묶어 봅시다.

t = ((202101, '홍길동'), (202103, '이철수'))
print(t)
print(t[0])
해설 — 튜플은 소괄호로 만들고 인덱스로 꺼냅니다. 원소를 바꿀 수 없어 지켜야 할 값에 알맞습니다.

예제 8-2

1, 3, 5가 반복되는 길이 1,000짜리 튜플을 만들어 봅시다.

t = (1, 3, 5) * 333 + (1,)
print('튜플의 길이:', len(t))
print('원소 1의 개수:', t.count(1))
print('앞부분:', t[:7])
해설 — 튜플도 덧셈·곱셈을 할 수 있습니다. 원소가 하나인 튜플은 (1,)처럼 쉼표를 붙여야 합니다.

0-9 집합

중복을 허용하지 않고 순서가 없는 그릇입니다. 수학의 집합 연산을 그대로 쓸 수 있습니다.

예제 9-1

두 집합의 교집합과 합집합을 구해 봅시다.

a = {1, 2, 3}
b = {3, 4, 5}
print('교집합:', a & b)
print('합집합:', a | b)
print('차집합:', a - b)
해설 — 교집합 &, 합집합 |, 차집합 -, 대칭 차집합 ^. 순서가 없어 인덱스로 꺼낼 수 없습니다.

예제 9-2

리스트에서 중복을 없애 봅시다.

a = [1, 2, 3] * 3
print('수정 전:', a)
b = list(set(a))
print('수정 후:', b)
해설 — set()으로 바꾸면 중복이 사라지고, 다시 list()로 바꿔 씁니다.

0-10 사전(딕셔너리)

키와 값을 짝지어 저장합니다. 이름으로 값을 바로 찾을 수 있어 그래프·메모이제이션에 자주 씁니다.

예제 10-1

자판기 버튼 번호와 음료를 사전으로 만들어 봅시다.

a = {1: '커피', 2: '이온 음료', 3: '과일주스'}
print(a.keys())
print(a.values())
print(a[2])
해설 — {키: 값} 형태이며 키는 겹치면 안 됩니다. keys()는 모든 키, values()는 모든 값을 돌려줍니다.

예제 10-2

빈 사전에 상보적인 염기쌍(A–T, G–C)을 하나씩 추가해 봅시다.

a = {}
a['A'] = 'T'   # 아데닌과 티민
a['T'] = 'A'
a['G'] = 'C'   # 구아닌과 사이토신
a['C'] = 'G'
print(a)
해설 — a[키] = 값으로 새 쌍을 추가하거나 바꿉니다. 빈 사전은 {}, 빈 집합은 set()으로 만듭니다.
