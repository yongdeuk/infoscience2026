Ⅰ 프로그래밍 · 10문제

Q1함수를 호출할 때 괄호 안에 넣어 실제로 전달하는 값을 무엇이라고 하나요?

해설 — 호출할 때 넣는 값이 인수, 정의할 때 괄호 안에 적어 그 값을 받는 변수가 매개 변수입니다.

Q2다음 코드의 실행 결과는?

def add(a, b=10):
    return a + b

print(add(5))

해설 — b를 생략했으므로 기본값 10이 쓰여 5 + 10 = 15입니다.

Q3다음 코드의 실행 결과는?

x = 1
def f():
    x = 5
    return x

f()
print(x)

해설 — 함수 안의 x = 5는 새 지역 변수를 만들 뿐 전역 변수 x는 바뀌지 않습니다. 전역 x를 바꾸려면 global x가 필요합니다.

Q4return이 없는 함수를 호출해 그 결과를 출력하면 무엇이 나오나요?

해설 — 반환값이 없는 함수는 자동으로 None을 돌려줍니다.

Q5다음 코드의 실행 결과는?

def total(*nums):
    return sum(nums)

print(total(1, 2, 3, 4))

해설 — *nums는 가변 인수로, 넘긴 값들을 튜플 (1, 2, 3, 4)로 받습니다. 합은 10입니다.

Q6클래스와 객체에 대한 설명으로 옳은 것은?

해설 — 클래스가 설계도이고 객체는 그 실체이며, 한 클래스로 여러 객체를 만들 수 있습니다. 생성자 __init__은 객체 생성 시 자동 실행되고, 메서드를 정의할 때는 self를 첫 매개 변수로 적어야 합니다.

Q7import random 후 1부터 6 사이 정수 하나를 무작위로 뽑는 코드는?

해설 — random.randint(a, b)는 a 이상 b 이하의 정수를 돌려줍니다. 양 끝을 모두 포함합니다.

Q8재귀 함수에 반드시 있어야 하는 것은?

해설 — 더 이상 자기 자신을 부르지 않는 종료 조건이 없으면 호출이 끝없이 쌓여 RecursionError가 납니다.

Q9다음 코드의 실행 결과는?

def f(n):
    if n == 0:
        return 0
    return n + f(n - 1)

print(f(4))

해설 — f(4) = 4 + f(3) = 4 + 3 + 2 + 1 + 0 = 10. 1부터 n까지의 합을 재귀로 구합니다.

Q10원판 4개짜리 하노이 탑을 옮기는 최소 이동 횟수는?

해설 — 최소 이동 횟수는 2ⁿ − 1입니다. 2⁴ − 1 = 15번.

Ⅱ 데이터 구조 · 10문제

Q1나중에 넣은 데이터가 가장 먼저 나오는(LIFO) 데이터 구조는?

해설 — 스택은 top 한쪽으로만 넣고 빼므로 마지막에 넣은 것이 먼저 나옵니다.

Q2빈 스택에 push(1), push(2), pop(), push(3), push(4), pop() 을 차례로 하면 남는 것은? (아래 → 위)

해설 — [1] → [1,2] → pop하면 [1] → [1,3] → [1,3,4] → pop하면 [1, 3].

Q3빈 큐에 A, B, C를 차례로 넣고 한 번 꺼낸 뒤 D를 넣었습니다. 다음에 꺼내지는 것은?

해설 — 큐는 먼저 들어온 것이 먼저 나옵니다. A가 이미 나갔으므로 다음은 B입니다.

Q4다음 중 큐가 어울리는 상황은?

해설 — 먼저 요청한 인쇄물이 먼저 나와야 하므로 큐입니다. 나머지는 가장 최근 것을 먼저 꺼내는 스택의 예입니다.

Q5파이썬 리스트 s를 스택으로 쓸 때, 꺼내지 않고 top의 값만 보는 코드는?

해설 — top은 리스트의 마지막 원소이므로 s[-1]로 봅니다. s.pop()은 꺼내 버립니다.

Q6노드가 10개인 트리의 간선 수는?

해설 — 루트를 뺀 모든 노드는 부모와 이어지는 간선을 하나씩 가지므로 n − 1 = 9개입니다.

Q7이진 탐색 트리에 50, 30, 70, 20, 40 을 차례로 넣었습니다. 40은 어디에 놓이나요?

해설 — 40 < 50이므로 왼쪽(30)으로, 40 > 30이므로 30의 오른쪽 자식이 됩니다. 실습실 이진 탐색 트리에서 직접 넣어 보세요.

Q8이진 탐색 트리를 중위 순회(왼쪽 → 루트 → 오른쪽)하면 값이 어떤 순서로 나오나요?

해설 — 왼쪽에는 작은 값, 오른쪽에는 큰 값이 있으므로 중위 순회하면 오름차순으로 정렬된 결과가 나옵니다.

Q9너비 우선 탐색(BFS)에 쓰는 데이터 구조는?

해설 — BFS는 가까운 노드부터 차례로 방문하므로 먼저 발견한 노드를 먼저 꺼내는 큐를 씁니다. DFS는 스택(또는 재귀)을 씁니다.

Q10노드는 많지만 간선이 아주 적은 그래프를 저장할 때 메모리를 아끼는 방법은?

해설 — 인접 행렬은 노드 수의 제곱만큼 칸이 필요하지만 인접 리스트는 실제 연결된 간선만 저장합니다.

Ⅲ 알고리즘 · 10문제

Q1알고리즘이 갖추어야 할 조건이 아닌 것은?

해설 — 알고리즘은 유한한 단계 안에 반드시 끝나야 합니다(유한성).

Q2다음 중 입력 크기 n이 커질 때 가장 빠르게 증가하는 것은?

해설 — 증가 순서는 O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)입니다.

Q3다음 코드의 시간 복잡도는?

for i in range(n):
    for j in range(n):
        print(i, j)

해설 — 바깥 반복 n번마다 안쪽이 n번씩 돌아 n × n = O(n²)입니다.

Q4정렬된 1,024개의 자료에서 이진 탐색으로 값을 찾을 때 최대 비교 횟수에 가장 가까운 것은?

해설 — 한 번 비교할 때마다 절반씩 버리므로 2¹⁰ = 1,024 → 약 10~11번이면 찾습니다. O(log n).

Q5이진 탐색을 쓰기 위한 조건은?

해설 — 가운데 값과 비교해 한쪽을 버리려면 자료가 크기순으로 정렬되어 있어야 합니다.

Q6동전 종류가 1원, 4원, 6원일 때 8원을 거슬러 주는 상황입니다. 큰 동전부터 고르는 탐욕법의 결과와 최적해의 동전 개수는?

해설 — 탐욕법은 6 + 1 + 1 = 3개를 고르지만, 4 + 4 = 2개가 최적입니다. 탐욕법이 항상 최적해를 보장하지는 않습니다.

Q7해를 만들어 가다가 조건을 어기면 바로 이전 단계로 돌아가 다른 선택을 하는 방법은?

해설 — 백트래킹입니다. N-퀸 문제에서 퀸이 서로 공격하게 되면 바로 되돌아갑니다.

Q8퀵 정렬이 속하는 알고리즘 설계 방법은?

해설 — 피벗을 기준으로 리스트를 나누고(분할) 각각 재귀로 정렬(정복)하므로 분할 정복입니다.

Q9재귀로 구현한 피보나치 함수가 느린 가장 큰 까닭은?

def fib(n):
    if n <= 2:
        return 1
    return fib(n - 1) + fib(n - 2)

해설 — fib(3), fib(2)처럼 같은 부분 문제를 반복해서 계산합니다(중복 부분 문제). 결과를 저장해 두는 메모이제이션으로 해결합니다.

Q10동적 계획법을 쓸 수 있는 문제의 성질 두 가지로 옳은 것은?

해설 — 큰 문제의 최적해가 부분 문제의 최적해로 이루어지고(최적 부분 구조), 같은 부분 문제가 반복될 때(중복 부분 문제) 동적 계획법이 효과적입니다.

Ⅳ 정보과학 프로젝트 · 10문제

Q1문제 해결 5단계의 순서로 옳은 것은?

해설 — 문제 발견 → 문제 구조화 → 알고리즘 설계 → 프로그램 구현 → 검증·공유 순서입니다.

Q2문제의 핵심만 남기고 불필요한 세부 사항을 덜어 내는 것은?

해설 — 추상화입니다. 지도를 노드와 간선만 남긴 그래프로 바꾸는 것이 대표적인 예입니다.

Q3급식 잔반을 줄이는 식단 조합을 찾을 때, 가능한 모든 조합을 빠짐없이 비교하는 방법은?

해설 — 모든 후보를 확인하는 전체 탐색은 후보 수가 적을 때 확실하게 최적해를 찾습니다.

Q4집에서 학교까지 가는 여러 경로 가운데 탄소 배출이 가장 적은 경로를 찾을 때 알맞은 알고리즘은?

해설 — 경로마다 배출량을 가중치로 둔 그래프에서 최단(최소) 경로를 구하는 다익스트라 알고리즘을 씁니다.

Q5다익스트라 알고리즘이 매 단계에서 하는 일은?

해설 — 확정되지 않은 노드 중 현재 거리가 가장 짧은 노드를 하나 골라 확정하고, 그 이웃의 거리를 갱신합니다.

Q6교실 자리 배치에서 ‘시력이 나쁜 학생은 앞줄’처럼 반드시 지켜야 하는 조건을 무엇이라고 하나요?

해설 — 해가 꼭 만족해야 하는 제약 조건입니다. 백트래킹은 제약 조건을 어기는 순간 되돌아갑니다.

Q7프로그램을 검증할 때 테스트 케이스로 꼭 넣어야 하는 것은?

해설 — 0, 최댓값, 빈 입력처럼 경계값과 예외 상황에서 오류가 자주 숨어 있습니다.

Q8모둠 프로젝트에서 생성형 AI를 활용한 경우 옳은 태도는?

해설 — AI 사용 신호등에 따라 사용 범위를 지키고, 사용 내용을 기록하며, 결과를 직접 확인합니다.

Q9다음 중 ‘문제 구조화’ 단계에서 하는 일은?

해설 — 문제 구조화에서는 현재 상태·목표 상태·조건을 정하고 어떤 데이터가 필요한지 정리합니다.

Q10탄소 발자국 계산 프로그램에서 ‘교통수단별 1km당 배출량’을 저장하기에 가장 알맞은 파이썬 자료형은?

해설 — 교통수단 이름을 키, 배출량을 값으로 두는 딕셔너리가 알맞습니다. 예: {'버스': 0.03, '자동차': 0.21}.
