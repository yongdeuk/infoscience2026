    교과서 · Ⅰ 1-1 함수의 이해

    여러 줄짜리 작업을 이름 하나로 묶어 두고, 필요할 때마다 불러 쓰는 장치가 함수입니다.

    이 시간에 배울 내용

    프로그래밍에서 함수를 어떻게 활용할까?

    • 함수가 무엇인지 알고, def로 함수를 만들 수 있어요.
    • 함수를 부르고(호출) 결과를 돌려받는(반환) 과정을 설명할 수 있어요.
    • 지역 변수와 전역 변수가 어떻게 다른지 구분할 수 있어요.
    생활 속 이야기 · 우리 집 로봇

    우리 집에 요리 로봇이 왔어요. “라면 끓여 줘!”라고 했더니 로봇이 멀뚱멀뚱 서 있어요. 로봇은 ‘라면 끓이기’가 무엇인지 몰라요. 그래서 매번 이렇게 말해 줘야 해요.

    “물 550mL를 끓여. 면과 수프를 넣어. 5분 동안 끓여. 불을 꺼. 그릇에 담아.”

    배고플 때마다 다섯 문장을 다 말해야 한다면 너무 귀찮겠죠? 한 번만 가르쳐 두고 “라면 끓여 줘” 한마디로 끝낼 수는 없을까요?

    쉽게 말하면

    로봇에게 “라면 끓여 줘”라고 한마디만 하면 되는 이유는, ‘물 550mL 끓이기 → 면과 수프 넣기 → 5분 끓이기 → 불 끄기 → 그릇에 담기’를 ‘라면 끓이기’라는 이름 하나로 묶어 두었기 때문입니다. 이 묶음이 함수이고, ‘라면 3개’, ‘계란 추가’처럼 바꿔 넣는 값이 매개 변수입니다.

    내장 함수
    파이썬이 미리 만들어 둔 함수

    print(), sum(), len(), input()처럼 바로 쓸 수 있어요. sum([1, 2])는 3, sum([3, 4])는 7을 돌려줘요.

    사용자 정의 함수
    내가 직접 만드는 함수

    내장 함수만으로 모자랄 때, 필요한 기능을 def로 직접 만들어요. 이 시간에 배울 내용이에요.

    직접 해 보기
    라면 로봇 — 함수를 한 번 가르치고 여러 번 부르기

    개수와 계란 옵션을 바꿔 가며 여러 번 호출해 보세요. 함수의 본문(다섯 단계)은 한 번만 적었는데, 부를 때마다 넣어 준 값에 맞게 다시 실행돼요.

    함수의 구조

    함수는 특정한 작업을 수행하도록 작성된 독립적인 코드 블록입니다. 파이썬이 미리 준비해 둔 내장 함수(print(), sum())와, 필요에 따라 직접 만드는 사용자 정의 함수가 있습니다.

     함수명(매개 변수1, 매개 변수2, ... ):
    실행할 문장
     반환값
    구성 요소설명필수 여부
    함수명고유한 함수 이름필수
    매개 변수인수를 전달받기 위해 사용하는 변수생략 가능
    함수 본문기능을 실행하기 위한 명령어(들여쓰기로 구분)필수
    반환값처리 결과를 호출한 쪽으로 되돌려주는 값생략 가능

    빈칸

    내장 함수 써 보기

    파이썬이 미리 만들어 둔 내장 함수로 점수 목록의 합계, 최고점, 과목 수를 구해요. 빈칸에 알맞은 함수 이름을 넣으세요.

    scores = [80, 95, 70]
print('합계:', ___(scores))
print('최고점:', ___(scores))
print('과목 수:', ___(scores))
    힌트

    합은 sum, 가장 큰 값은 max, 개수(길이)는 len이에요.

    정답 코드 보기
    scores = [80, 95, 70]
print('합계:', sum(scores))
print('최고점:', max(scores))
print('과목 수:', len(scores))
    고치기

    라면 끓이기 함수

    라면 끓이는 과정을 make_ramen() 함수로 묶었는데, 실행하면 오류가 나요. 고쳐서 라면 2개를 끓이는 과정이 출력되게 하세요. (고칠 곳 2군데)

    def make_ramen(count)
    print('물', 550 * count, 'mL 끓이기')
    print('면과 수프', count, '개 넣기')
    print('5분 끓이고 그릇에 담기')

# 여기서 함수를 불러 라면 2개를 끓이세요
    힌트

    def 줄 끝에는 무엇이 있어야 하나요? 그리고 함수는 정의만 해서는 실행되지 않아요.

    정답 코드 보기
    def make_ramen(count):
    print('물', 550 * count, 'mL 끓이기')
    print('면과 수프', count, '개 넣기')
    print('5분 끓이고 그릇에 담기')

make_ramen(2)

    4확인 문제

    Q1다음 중 사용자 정의 함수는 무엇일까요?

    해설 — print, sum, len은 파이썬이 미리 준비한 내장 함수예요. def로 직접 만든 함수가 사용자 정의 함수예요.

    Q2함수의 구성 요소 중 생략할 수 있는 것끼리 묶은 것은?

    해설 — 함수명과 본문은 꼭 있어야 하고, 매개 변수와 반환값은 필요할 때만 써요.
