# 정보과학

고등학교 『정보과학』(씨마스, 2022 개정 교육과정)의 4개 대단원을 **그림·표·짧은 코드**로 정리한 학습 웹페이지입니다.
1학기 주 3시간(16주) 수업의 학습 내용을 중학생 수준에서도 이해할 수 있게 풀어 썼습니다.

🔗 **https://infoscience2026.vercel.app/**

(예비 주소: https://yongdeuk.github.io/infoscience2026/)

## 구성

| 단원 | 내용 |
|---|---|
| Ⅰ 프로그래밍 | 함수의 구조·호출과 반환·변수의 범위, 기본값/가변 인수 매개 변수, 클래스와 객체, 모듈·패키지·라이브러리, 재귀 구조와 하노이 탑 |
| Ⅱ 데이터 구조 | 스택(LIFO)·큐(FIFO), 트리와 이진 탐색 트리, 그래프의 종류와 DFS·BFS |
| Ⅲ 알고리즘 | 시간 복잡도와 빅오 표기법, 상태 공간·전체/부분 탐색, 이진 탐색·탐욕법·백트래킹, 분할 정복과 퀵 정렬, 동적 계획법 |
| Ⅳ 정보과학 프로젝트 | 문제 해결 5단계, 급식 잔반 최소화·탄소 발자국 계산·교실 자리 배치 프로젝트 |

## 특징

- **1학기 16주차 운영 계획** — 주 3시간·16주(총 48시간) 기준으로 주차별 학습 내용을 나누었고, 단원 카드와 각 소단원 제목에 해당 주차를 표시
- **직접 조작해 보는 실습 위젯 7개** — 스택 시뮬레이터, 스택 vs 큐 동시 비교, 재귀 호출 스택 따라가기, 하노이 탑(자동 풀이 포함), 이진 탐색 단계 실행, 재귀 vs 동적 계획법 호출 횟수 비교, 빅오 증가율 비교
- 교과서 본문을 빠지지 않게 반영 — **파이썬 예제 코드 96개**, 교과서의 ‘정보과학으로 지식 키우기(보충·심화)’, ‘스스로 해결하기’, ‘역량 키우기 수행 활동’을 상자로 구분해 수록
- 개념마다 **직접 그린 SVG 다이어그램 22종** — 함수 호출/반환 흐름, 재귀 호출-반환 사다리, 스택·큐 입출구 비교, 이진 탐색 트리 탐색 경로, DFS vs BFS 방문 순서, 빅오 성장 곡선, 탐욕법이 실패하는 사례, 동적 테이블 채우기 등
- **“쉽게 말하면”** 비유 상자 — 라면 끓이기 로봇, 마트료시카, 핫케이크 더미, 매표소 대기 줄, 호텔 층 표지판
- 소단원마다 **“핵심 포인트”** 요약
- 단원별 색 구분, 다크 모드 지원, 모바일 대응
- **단원별 페이지 분리** — 홈 + 4개 단원 페이지. 상단 메뉴로 단원을 오가고, 각 페이지 왼쪽 목차가 **현재 읽는 위치를 실시간으로 표시**(휴대폰에서는 화면 상단에 표시 + 진행률 막대)
- 본문 글자 크기를 기본보다 **1.3배** 키워 교실 화면에서도 읽기 편함
- 외부 라이브러리·폰트 없이 **순수 HTML·CSS·JavaScript**로 동작

## 구조

```
index.html          홈 — 단원 카드와 16주차 운영 계획
unit1.html ~ unit4.html   단원별 본문
assets/style.css    전체 공용 스타일
assets/app.js       실습 위젯 + 스크롤 위치 표시
src/infoscience.html   편집용 단일 파일 원본
build.py            원본을 페이지로 분리하는 빌드 스크립트
```

## 수정하는 방법

내용은 `src/infoscience.html` 을 고친 뒤, 저장소 루트에서 아래를 실행하면 페이지가 다시 만들어집니다.

```bash
python build.py
```
