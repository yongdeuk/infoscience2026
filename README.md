# 에듀플로 정보과학

고등학교 『정보과학』(씨마스, 2022 개정 교육과정)의 4개 대단원을 **그림·표·짧은 코드**로 정리한 학습 웹페이지입니다.
1학기 주 3시간 수업의 학습 내용을 중학생 수준에서도 이해할 수 있게 풀어 썼습니다.

🔗 **https://yongdeuk.github.io/infoscience2026/**

## 구성

| 단원 | 내용 |
|---|---|
| Ⅰ 프로그래밍 | 함수의 구조·호출과 반환·변수의 범위, 기본값/가변 인수 매개 변수, 클래스와 객체, 모듈·패키지·라이브러리, 재귀 구조와 하노이 탑 |
| Ⅱ 데이터 구조 | 스택(LIFO)·큐(FIFO), 트리와 이진 탐색 트리, 그래프의 종류와 DFS·BFS |
| Ⅲ 알고리즘 | 시간 복잡도와 빅오 표기법, 상태 공간·전체/부분 탐색, 이진 탐색·탐욕법·백트래킹, 분할 정복과 퀵 정렬, 동적 계획법 |
| Ⅳ 정보과학 프로젝트 | 문제 해결 5단계, 급식 잔반 최소화·탄소 발자국 계산·교실 자리 배치 프로젝트 |

## 특징

- 개념마다 **직접 그린 SVG 다이어그램 22종** — 함수 호출/반환 흐름, 재귀 호출-반환 사다리, 스택·큐 입출구 비교, 이진 탐색 트리 탐색 경로, DFS vs BFS 방문 순서, 빅오 성장 곡선, 탐욕법이 실패하는 사례, 동적 테이블 채우기 등
- **“쉽게 말하면”** 비유 상자 — 라면 끓이기 로봇, 마트료시카, 핫케이크 더미, 매표소 대기 줄, 호텔 층 표지판
- 소단원마다 **“핵심 포인트”** 요약
- 단원별 색 구분, 다크 모드 지원, 모바일 대응
- 외부 라이브러리·폰트 없이 **단일 HTML 파일**로 동작

## 사용

`index.html` 하나만 있으면 됩니다. 브라우저로 바로 열거나, 수업용 LMS에 그대로 올려서 쓸 수 있습니다.

## 참고

- 개념·예제 코드·수치는 교과서 본문을 근거로 정리했고, 그림은 이해를 돕기 위해 새로 그렸습니다.
- 저작권 문제로 **교과서 PDF 원본은 이 저장소에 포함하지 않습니다.** 자세한 예제와 ‘스스로 해결하기’ 활동은 교과서를 함께 보세요.
