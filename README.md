# 정보과학

씨마스 『정보과학』 **2022 개정 교육과정**의 핵심 내용을 정리한 학습 웹페이지입니다.
1학기 주 3시간(16주) 수업의 학습 내용을 중학생 수준에서도 이해할 수 있게 풀어 썼습니다.

**보문고등학교 김용득 선생님 제작**

🔗 **https://infoscience2026.vercel.app/**

(저장소는 비공개입니다. GitHub Pages는 무료 계정에서 비공개 저장소를 지원하지 않아 사용하지 않습니다.)

## 구성

| 단원 | 시기 | 내용 |
|---|---|---|
| 0 파이썬 기초 | 준비 | 변수와 출력, 자료형, 입력, 연산자, 조건문, 반복문, 리스트·튜플·집합·사전, Programiz 사용법 |
| Ⅰ 프로그래밍 | 1~5주 | 함수, 매개 변수, 클래스와 객체, 모듈·패키지, 재귀와 하노이 탑 |
| Ⅱ 데이터 구조 | 6~9주 | 스택·큐, 트리와 이진 탐색 트리, 그래프와 DFS·BFS |
| Ⅲ 알고리즘 | 10~13주 | 빅오, 상태 공간·전체 탐색, 이진 탐색·탐욕법·백트래킹, 분할 정복, 동적 계획법 |
| Ⅳ 정보과학 프로젝트 | 14~16주 | 문제 해결 5단계, 급식 잔반·탄소 발자국·자리 배치 프로젝트 |

**차시 수업** `lessons.html`, `lesson01~48.html`: 16주 × 3차시를 한 차시(50분)씩 진행합니다. 차시마다 순서가 같습니다.

1. **생각 열기**: 질문 하나, 관련 유튜브 영상(페이지 안에서 재생), 모두의 생각 보드, 관련 시뮬레이터 링크
2. **교과서로 배우기**: 교과서 내용 + 코드마다 **예측해 보기**, **코드 설명**(줄별 이유), 핵심 부분을 비운 **빈칸 코드**(빈칸 확인·정답)
3. **직접 해 보기**: 빈칸 → 고치기 → 만들기 실습. ▶ 실행하면 기대 출력과 비교해 바로 채점
4. **확인 문제** 2개 → 5. **한 줄 정리**(모두의 생각 보드, 선생님께 제출)

단원 페이지는 모두 같은 틀입니다: 단원 소개(목표·차시 계획·바로 가기) → 소단원 본문(왼쪽 목차, 소단원마다 **해 봤어요**) → 단원 마무리(**실습 모음 · 핵심 용어 · 단원 퀴즈 10문제 · Programiz 실습**).

| 수업 도구 | 내용 |
|---|---|
| `course.html` 수업 안내 | 과목 소개, 단원 목표, 평가(비율은 학교 평가 계획 확정 후 기입), 프로젝트 채점 기준, 수업 약속, AI 사용 신호등, 준비물, 질문하는 법 |
| `labs.html` 실습실 | 그래프 DFS·BFS, 이진 탐색 트리, 정렬 경주 시뮬레이터 + 본문 속 실습 바로 가기 |
| `practice.html` 파이썬 실습 | 단원별 실습 세트(칸마다 **Programiz에서 실행**), 검색되는 오류 해결표 |
| `glossary.html` 용어 사전 | 핵심 용어 114개, 검색·단원 필터, 본문 위치로 바로 가기 |
| `my.html` 내 학습 | 해 봤어요 진도, 단원 퀴즈 최고 점수, 정리 노트, txt 내보내기·인쇄 |

코드 실습은 **Programiz 온라인 컴파일러**(로그인·저장 없음)를 씁니다. 코드 블록의 **Programiz에서 실행** 버튼이 코드를 복사하고 Programiz를 열어 줍니다. 페이지 안의 ▶ 실행(Pyodide)도 그대로 쓸 수 있습니다.

학생 기록(해 봤어요·퀴즈 점수·노트)은 서버 없이 **학생 기기의 브라우저에만** 저장됩니다(`is.` 로 시작하는 키).

## 구조

```
build.py                 src/ 를 읽어 아래 페이지를 모두 만든다
settings.json            해마다 바뀌는 값: 학년도·학기, 학기 시작일, 평가 비율, 수행평가 채점 기준표 (교사 설정 페이지에서 고침)
assets/vendor/           교사 설정에서 엑셀 파일을 읽는 SheetJS 0.18.5 (Apache-2.0, 파일을 고를 때만 불러옴)
src/data/course.json     과목 정보, 단원(이름·주차·목표·할 수 있는 것), 16주 계획
src/data/glossary.json   용어 사전 (단원 마무리 '핵심 용어'와 glossary.html에 함께 쓰임)
src/data/quiz.json       단원 퀴즈 (단원별 10문제)
src/data/lessons.json    차시 ↔ 교과서 부분 연결(tN-M:청크, #문제, !역량), 차시별 시뮬레이터 링크
src/lessons/LNN.json     차시별 목표·생각 열기·코드 설명·빈칸·실습(기대 출력)·확인 문제·한 줄 정리
tools/lessonlib.py       단원 본문을 차시 단위로 자르는 도구
apps-script/Code.gs      제출·모두의 생각 보드를 받는 구글 앱스 스크립트(교사 시트에 붙여 넣음)
src/units/unit0~4.html   단원 본문 (소단원 <article class="topic">)
src/pages/*.html         수업 안내·실습실·파이썬 실습·내 학습·교사 설정 본문
src/css/*.css            base(디자인) · content(본문 요소) · tools(도구·시뮬레이터)
src/js/*.js              widgets(실습 위젯·실행기) · tools(진도·퀴즈·용어·Programiz·시뮬레이터)

index.html, unit0~4.html, lessons.html, lesson01~48.html, course.html, labs.html, practice.html, glossary.html, my.html
assets/site.css, assets/site.js        ← 빌드 결과물 (직접 고치지 않기)
```

## 수정하는 방법

`src/` 아래 파일을 고친 뒤 저장소 루트에서 실행합니다.

```bash
python build.py
```

- **학기 시작일과 평가 비율은 `settings.html`(교사 설정)에서 고칩니다.** 메뉴에는 없고, 페이지 맨 아래 **정보과학** 글자를 5번 연속 누르면 들어갑니다(링크를 숨기는 장치일 뿐, 실제 저장은 저장소 주인의 GitHub 로그인이 있어야 됩니다). 값을 고치고 **복사하고 GitHub 편집 창 열기**를 누른 뒤, 열린 `settings.json` 편집 창에 붙여 넣고 커밋하면 배포 후 모든 화면에 반영됩니다. 사이트가 `settings.json`을 실행 중에 읽기 때문에 다시 빌드할 필요가 없습니다. 저장 전에 **이 기기에서만 미리 보기**로 확인할 수 있습니다. 수행평가 채점 기준표는 같은 페이지에서 엑셀·CSV 파일을 올리거나 한글·엑셀 표를 복사해 붙여 넣으면 됩니다.
- **제출·모두의 생각 보드**: 교사 설정의 **제출·보드** 칸에 구글 앱스 스크립트 웹 앱 주소를 넣으면 켜집니다(설정 페이지에 연결 순서가 있습니다). 학생 이름·학번과 제출 내용은 교사의 구글 시트(`제출`, `보드` 시트)에만 저장되고, 보드 화면에는 이름 없이 오늘 쓴 내용만 보입니다. 비워 두면 둘 다 숨겨집니다.
- **차시별 생각 열기 영상·시뮬레이터 링크**는 `settings.json`의 `videos`·`sims`에 있고, 교사 설정의 **차시 영상·시뮬레이터** 표에서 유튜브 주소와 시뮬레이터 링크(`이름 | 주소`)를 바꾸거나 비울 수 있습니다(빌드 필요 없음).
- **이번 주**는 학기 시작일로 자동 계산하고, 교사 설정의 **이번 주 직접 정하기**로 바꿀 수 있습니다.
- 학생 화면에는 **차시 수업**만 연결됩니다. 단원 페이지(`unit1~4.html`)는 만들어 두지만 메뉴·홈·용어 사전의 링크는 해당 차시로 바뀝니다(0단원 파이썬 기초는 그대로).
- 차시 내용은 `src/lessons/LNN.json`을 고친 뒤 다시 빌드합니다. 코드 설명·빈칸은 차시 페이지의 코드 블록 순서(`C1`, `C2`…)를 따릅니다.
- 용어·퀴즈는 JSON에 항목을 더하면 단원 페이지와 용어 사전에 함께 반영됩니다.

## 참고

- 개념·예제 코드·수치는 교과서 본문을 근거로 정리했고, 그림은 이해를 돕기 위해 새로 그렸습니다.
