    3직접 해 보기

    코드를 고쳐서 ▶ 실행하면 출력이 맞는지 바로 알려 줘요. 막히면 힌트부터 열어 보세요.

    빈칸

    import 세 가지 방법

    표준 라이브러리 math를 세 가지 방법으로 불러와 써 봐요. 호출하는 모양을 보고 빈칸에 알맞은 것을 넣으세요.

    import math
print(math.sqrt(16))

import math as ___
print(m.factorial(5))

from math import ___
print(gcd(48, 18))
    힌트

    as 뒤의 이름이 별명이 돼요. from … import 이름으로 가져오면 모듈 이름 없이 바로 불러요.

    정답 코드 보기
    import math
print(math.sqrt(16))

import math as m
print(m.factorial(5))

from math import gcd
print(gcd(48, 18))
    고치기

    NameError 고치기

    import 방법과 호출 방법이 맞지 않아 NameError가 나요. import 줄은 그대로 두고 호출하는 두 줄만 고쳐서 5.0과 24가 나오게 하세요.

    import math as m
print(math.sqrt(25))

from math import factorial
print(math.factorial(4))
    힌트

    as m으로 불러오면 이 파일에서 math라는 이름은 없어요. from으로 가져온 함수는 이름만 써서 불러요.

    정답 코드 보기
    import math as m
print(m.sqrt(25))

from math import factorial
print(factorial(4))
    생각

    나만의 모듈 설계하기

    내가 mytools.py라는 모듈을 만든다면 어떤 함수 2개를 넣고 싶은지 적고, 다른 파일에서 그 함수를 불러 쓰는 import 문과 호출 문을 써 보세요. (모듈 파일은 호출하는 파일과 같은 위치에 있어야 해요.)

    4확인 문제

    Q1from spirograph import draw as d 로 불러왔을 때 draw 함수를 호출하는 올바른 방법은?

    해설 — as d로 별명을 붙였으니 d라는 이름으로 불러요.

    Q2모듈, 패키지, 라이브러리에 대한 설명으로 옳은 것은?

    해설 — 모듈 = .py 파일 하나, 패키지 = 모듈이 든 폴더, 라이브러리 = 그 전체 도구 모음이에요.
