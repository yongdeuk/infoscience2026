Ⅰ. 프로그래밍 · 1~5주차

1주차
  1. 오리엔테이션 — 정보과학은 무엇을 배우는 과목인가
  2. 함수의 개념 — 내장 함수와 사용자 정의 함수
  3. 함수의 정의(def)와 네 가지 구성 요소
2주차
  1. 함수 호출 — 인수와 매개 변수의 관계
  2. return의 두 역할 / 매개 변수·반환값 4가지 형태
  3. 지역 변수와 전역 변수, global
3주차
  1. [역량] 음악 플레이 리스트 관리 프로그램
  2. 기본값 매개 변수와 가변 인수 매개 변수
  3. 여러 값 반환 / 클래스와 객체
4주차
  1. 모듈 만들기와 import
  2. 패키지·라이브러리 / 내장 함수와 표준 라이브러리
  3. [역량] 가위바위보 게임 만들기
5주차
  1. 재귀 구조의 이해 — 수학적 귀납법과 재귀 관계
  2. 재귀 함수의 동작 원리 — 호출과 반환
  3. 반복 vs 재귀 / 재귀 활용 — 자릿수 합·하노이 탑

Ⅱ. 데이터 구조 · 6~9주차

6주차
  1. 데이터 구조의 분류 / 스택의 개념(LIFO)
  2. 스택의 연산 — push, pop, peek, isEmpty
  3. 리스트로 스택 구현하기 · 활용 사례
7주차
  1. 큐의 개념(FIFO)과 연산
  2. 리스트로 큐 구현하기 / 덱·우선순위 큐
  3. [역량] 스택·큐를 활용한 프로그램
8주차
  1. 트리의 개념과 구성 요소
  2. 트리의 표현 — 인접 행렬과 인접 리스트
  3. 이진 트리와 순차 데이터 구조 표현
9주차
  1. 이진 탐색 트리의 규칙과 활용
  2. 그래프의 개념·종류와 표현
  3. 그래프 탐색 — 깊이 우선·너비 우선 탐색

Ⅲ. 알고리즘 · 10~13주차

10주차
  1. 알고리즘의 이해와 문제 해결 전략 네 가지
  2. 알고리즘 성능 평가 — 시간·공간 복잡도
  3. 빅오 표기법과 알고리즘 성능 비교
11주차
  1. 문제의 세 요소와 상태 공간
  2. 탐색 공간의 구조·범위 / 전체 탐색과 순차 탐색
  3. 비선형 전체 탐색 — DFS·BFS 적용
12주차
  1. 탐색 공간 배제와 이진 탐색
  2. 탐욕 알고리즘 — 거스름돈·시간표 문제
  3. 분기 한정 알고리즘과 백트래킹
13주차
  1. 문제 분해와 전체·부분 문제의 관계식
  2. 분할 정복법 — 퀵 정렬과 합병 정렬
  3. 동적 계획법 — 메모이제이션과 상향식

14주차

  2. 학문 분야별 문제 탐색 / 모둠 구성·주제 선정
  3. [프로젝트 ①] 급식 잔반 — 문제 발견 및 구조화
15주차
  1. [프로젝트 ①] 알고리즘 설계와 프로그램 작성
  2. [프로젝트 ②] 탄소 발자국 — 데이터 수집과 구조화
  3. [프로젝트 ②] 다익스트라 알고리즘으로 구현하기

  1. [프로젝트 ③] 교실 자리 배치 — 요구 사항 분석과 설계
  2. [프로젝트 ③] 백트래킹 구현과 디버깅
