    def apply_discount(prices, ):
    for price in prices:
        sale = round(price * (1 - discount))
        print(f'정가 {price} → 판매가 {sale}원')

apply_discount([1000, 2000])        # 할인 없음(기본값 0)
apply_discount([1000, 2000], 0.3)   # 30% 할인

    문제 2 기본값 매개 변수로 인사하기 기초 · 매개 변수

    이름과 인사말을 받아 출력하는 greet(name, word='안녕하세요')를 작성하시오. 인사말을 주지 않으면 기본값을 쓴다.

    greet('민서')            →  민서님, 안녕하세요!
greet('지호', '반갑습니다')  →  지호님, 반갑습니다!
    정답과 해설

    기본값 매개 변수는 반드시 값을 받아야 하는 매개 변수보다 뒤에 놓아야 합니다.

    def greet(name, word='안녕하세요'):
    print(f'{name}님, {word}!')

greet('민서')
greet('지호', '반갑습니다')

    문제 3 점수가 몇 개든 평균 내기 중급 · 가변 인수

    점수를 개수 제한 없이 받아 평균을 반환하는 average(*scores)를 작성하시오. 점수가 하나도 없으면 0을 반환한다.

    average(80, 90, 100)  →  90.0
average()             →  0
    정답과 해설

    *scores는 전달된 인수를 모두 튜플로 묶습니다. 빈 튜플일 때 len()이 0이 되어 0으로 나누는 오류가 나므로 먼저 걸러 줍니다.

    def average(*scores):
    if not scores:              # 빈 튜플이면
        return 0
    return sum(scores) / len(scores)

print(average(80, 90, 100))   # 90.0
print(average())              # 0
