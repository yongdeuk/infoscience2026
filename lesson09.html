    콤마로 나열해 반환하면 튜플 하나로 묶여 나갑니다. 받는 쪽에서 변수 세 개로 풀면 됩니다.

    def stats(nums):
    return max(nums), min(nums), sum(nums) / len(nums)

hi, lo, avg = stats([12, 7, 25, 3])
print(hi, lo, avg)            # 25 3 11.75

    문제 10 은행 계좌 클래스 심화 · 클래스

    예금·출금·잔액 확인이 가능한 Account 클래스를 작성하시오. 잔액보다 많이 출금하려 하면 거절 메시지를 출력한다.

    계좌 개설: 민서 / 잔액 0원
입금 10000 → 잔액 10000원
출금 30000 → 잔액이 부족합니다.
출금 3000  → 잔액 7000원
    정답과 해설

    속성은 __init__에서 초기화하고, 각 메소드의 첫 매개 변수는 self로 둡니다.

    class Account:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
        print(f'계좌 개설: {owner} / 잔액 {balance}원')

    def deposit(self, amount):
        self.balance += amount
        print(f'입금 {amount} → 잔액 {self.balance}원')

    def withdraw(self, amount):
        if amount > self.balance:
            print(f'출금 {amount} → 잔액이 부족합니다.')
            return
        self.balance -= amount
        print(f'출금 {amount} → 잔액 {self.balance}원')

a = Account('민서')
a.deposit(10000)
a.withdraw(30000)
a.withdraw(3000)

    힌트

    메소드는 def 이름(self, …): 형태예요. 튜플을 쉼표로 이어 붙일 때는 ', '.join(sports)를 써요.

    정답 코드 보기
    class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

    def introduce(self):
        print(f'{self.grade}학년 {self.name}입니다.')

    def play_sports(self, *sports):
        print(f"{self.name}의 스포츠 클럽: {', '.join(sports)} ({len(sports)}개)")

s1 = Student('민서', 1)
s2 = Student('지호', 2)
s1.introduce()
s1.play_sports('농구', '축구', '탁구')
s2.introduce()
s2.play_sports('배드민턴')
