정보과학 프로젝트

앞의 세 단원에서 배운 것을 모두 꺼내 쓴다. 실생활 문제를 찾아 직접 프로그램으로 해결하는 단원.

1-1 정보과학과 문제 해결 14주차

데이터를 모으고 분석해서 실제 변화를 만들어 내는 과정, 그 표준 절차를 익힙니다.

단계구체적으로 하는 일
1. 문제 발견 및 구조화문제를 명확히 정의 → 관련 데이터 수집 → 작은 단위로 나누어 해결 방안 구조화
2. 알고리즘 설계필요한 데이터 설정 → 적합한 데이터 구조·알고리즘 선택 → 절차와 함수 설계
3. 프로그램 작성가독성·유지 보수성을 고려해 코딩, 팀원 간 협업, 테스트 코드 작성
4. 검증 및 디버깅다양한 테스트 케이스로 성능 평가 → 실행 흐름을 추적해 오류 원인 수정
5. 배포 및 유지 보수베타 테스트 → 사용자 피드백 반영 → 기능 개선과 모니터링
다른 학문 분야에서도 — 생명과학(유전자 편집 정확도), 화학(단백질 접힘 구조 예측), 지구과학(기후 변화 시뮬레이션), 물리학(중력파 탐지). 모두 “문제 구조화 → 알고리즘 설계”라는 같은 틀로 접근합니다.

1-2 프로젝트 ① 급식 잔반 최소화 14~15주차

카테고리마다 메뉴를 하나씩 골라 전체 잔반량이 가장 적은 조합을 찾습니다.

항목내용
문제 정의학교 급식 잔반량을 조사하고 줄일 방안을 찾는다
수집 데이터영양 선생님 면담(1인 평균 잔반 약 170g), 처리 비용(1톤당 13~15만 원), 잔반 1kg당 1.65kg CO₂
데이터 구조딕셔너리 — 메뉴명을 키, 잔반량·카테고리를 값으로
알고리즘동적 계획법 — 카테고리별 선택을 부분 문제로 나누고 중복 계산 제거
연결되는 단원Ⅲ-3-2 동적 계획법
해결 방안은 두 갈래로 구조화됩니다. 조리량 조정(메뉴별 잔반 데이터 분석·선호도 조사·미식사 인원 사전 조사)과 학생 인식 개선(환경 영향 교육·메뉴 계획 참여·책임 의식 부여). UN 지속가능발전목표 12. 책임있는 소비와 생산과 연결됩니다.

2-1 프로젝트 ② 탄소 발자국 계산 15주차

장소를 노드, 이동할 때 나오는 탄소 배출량을 가중치로 놓고 최소 배출 경로를 찾습니다.

항목내용
문제 정의일상 활동의 탄소 발자국을 계산하고 줄일 방법을 제안한다
기본 공식탄소 발자국 = 활동량 × 배출 계수
전기 1kWh 0.474 · 버스 1km 0.1 · 쌀 1kg 2.7 · 소고기 1kg 27 · 채소 1kg 0.5
데이터 구조딕셔너리 · 우선순위 큐 · 그래프
알고리즘다익스트라 알고리즘 — 한 노드에서 다른 모든 노드까지의 최단(최소 배출) 경로
연결되는 단원Ⅱ-1-2 큐(우선순위 큐), Ⅱ-2-2 그래프
우선순위 큐를 쓰면 지금까지 배출량이 가장 적은 경로부터 먼저 처리하고, 이미 확정된 노드는 다시 보지 않습니다. Ⅲ단원에서 배운 탐색 공간 배제가 그대로 적용된 사례입니다. UN 지속가능발전목표 13. 기후 행동과 연결됩니다.

2-2 프로젝트 ③ 교실 자리 배치 16주차

고정 자리, 선호 자리, 이전 자리 회피 — 여러 조건을 동시에 만족시키는 배치를 찾습니다.

항목내용
요구 사항 우선순위① 고정 자리 배정 → ② 선호하는 자리 → ③ 이전 자리 안 앉기 → ④ 무작위 배정
데이터교실 데이터(행×열 2차원 격자), 학생 데이터(.csv 파일)
데이터 구조클래스 — Student, Classroom 객체로 관리
알고리즘전체 탐색 + 백트래킹 — 배치가 막히면 이전 단계로 되돌아가 다른 자리를 시도
연결되는 단원Ⅰ-1-2 클래스와 객체, Ⅲ-2-2 분기 한정·백트래킹
왜 클래스를 쓸까? 학생 한 명이 이름·고정 자리·선호 자리·이전 자리·이전 짝을 한꺼번에 갖고 있기 때문입니다. 관련된 데이터와 기능을 하나의 객체로 묶으면 코드가 훨씬 정리됩니다. UN 지속가능발전목표 4. 양질의 교육과 연결됩니다.
세 프로젝트를 관통하는 것
  • 모두 문제 발견 → 구조화 → 알고리즘 선택 → 구현 → 검증의 같은 절차를 따른다.
  • 알고리즘은 새로 배우는 것이 아니라 Ⅱ·Ⅲ단원에서 배운 것을 고르는 것이다.
  • 데이터 구조 선택(딕셔너리·우선순위 큐·클래스)이 코드의 난이도를 결정한다.
  • 완벽한 답보다 실행 가능하고 개선 가능한 해결책을 만드는 것이 목표.
