1생각 열기

고기·야채·국·반찬에서 하나씩 고르는 식단은 81가지예요. 손으로 81번 더해 볼 수도 있지만, 컴퓨터에게 ‘겹치는 계산 없이’ 시키려면 어떻게 말해야 할까요?

    코드 아래 💡 코드 설명을 펼쳐 보고, 빈칸이 있으면 채운 뒤 실행해 보세요.

    교과서 · Ⅳ 1-2 프로젝트 ① 급식 잔반 최소화

    2단계 · 알고리즘 설계

    프로그램이 풀 문제를 또렷하게 정해요. “고기·야채·국·반찬에서 메뉴를 하나씩 골라, 전체 잔반량이 가장 적은 조합을 찾는다.”

    직접 해 보기
    식단 짜기 — 잔반이 가장 적은 조합 찾기
    —이 식단의 잔반량
    0시험한 식단

    여기서는 줄마다 가장 적은 메뉴를 고르면 되지만, “같은 재료를 두 번 쓰지 않기” 같은 조건이 붙으면 그렇게 풀 수 없어요. 그래서 모든 경우를 빠짐없이, 그러나 겹치는 계산 없이 살피는 알고리즘이 필요해요.

    설계 항목내용
    1. 데이터 설정메뉴 데이터(menu_data) — 메뉴마다 잔반량 / 카테고리 데이터(categories) — 메뉴를 고기·야채·국·반찬으로 분류
    2. 알고리즘 선택데이터 구조는 딕셔너리, 알고리즘은 동적 계획법. 카테고리를 하나씩 넘어가며 메뉴를 고르고, 각 단계의 최소 잔반량을 계산해 저장해 둬요.
    3. 프로그래밍 순서데이터 입력 → 알고리즘 구현(카테고리 개수 계산, 재귀 함수의 종료 조건·중복 확인·초기화, 최소 조합 찾기) → 메인 함수 실행 및 결과 출력
    쉽게 말하면 · 딕셔너리

    딕셔너리는 이름표가 붙은 서랍장이에요. ‘김치’라는 이름표(키)가 붙은 서랍을 열면 그 안에 ‘잔반 15g’(값)이 들어 있어요. 이름표는 서로 달라야 하고, 이름만 알면 값을 바로 꺼낼 수 있어요. 파이썬에서는 {'김치': 15}처럼 써요.

    3단계 · 프로그램 작성

    ① 데이터 입력 — 딕셔너리로 메뉴와 카테고리 정의

    menu_data = {                                 # 메뉴 이름: {'waste': 잔반량}
    '닭고기': {'waste': 40}, '돼지고기': {'waste': 50}, '소고기': {'waste': 30},
    '브로콜리': {'waste': 20}, '시금치': {'waste': 25}, '양배추': {'waste': 35},
    '미역국': {'waste': 50}, '된장국': {'waste': 20}, '김치찌개': {'waste': 40},
    '김치': {'waste': 15}, '멸치볶음': {'waste': 35}, '나물': {'waste': 25}
}
categories = {                                # 카테고리: [그 안의 메뉴들]
    '고기': ['닭고기', '돼지고기', '소고기'],
    '야채': ['브로콜리', '시금치', '양배추'],
    '국':   ['미역국', '된장국', '김치찌개'],
    '반찬': ['김치', '멸치볶음', '나물']
}

    ② 알고리즘 구현 — 동적 계획법

    def dp_minimize_waste(menu_data, categories):
    category_keys = list(categories.keys())   # (1) ['고기', '야채', '국', '반찬']
    n = len(category_keys)                    #     카테고리 개수 = 4
    dp = {}                                   #     동적 테이블(이미 계산한 결과 저장)

    def get_min_waste(index, chosen):         # index번째 카테고리부터 골라 나감
        if index == n:                        # (2)-① 종료 조건: 모두 골랐으면
            return 0, []                      #      더할 잔반 0, 빈 조합
        if (index, tuple(chosen)) in dp:      # (2)-② 중복 확인: 계산한 적 있으면
            return dp[(index, tuple(chosen))] #      저장된 값을 그대로

        min_waste = float('inf')              # (2)-③ 초기화: 최소 잔반은 무한대에서 시작
        best_combination = []

        current_category = category_keys[index]          # (3) 이번 카테고리의 메뉴를 하나씩
        for menu in categories[current_category]:
            if menu not in chosen:
                # 다음 카테고리로 넘어가 나머지의 최소 잔반을 구함 (재귀 호출)
                waste, combination = get_min_waste(index + 1, chosen + [menu])
                waste += menu_data[menu]['waste']        # 이번 메뉴의 잔반을 더함
                if waste < min_waste:                    # 더 적으면 기록 갱신
                    min_waste = waste
                    best_combination = [menu] + combination

        dp[(index, tuple(chosen))] = (min_waste, best_combination)   # 결과 저장
        return dp[(index, tuple(chosen))]

    min_waste, best_combination = get_min_waste(0, [])   # (4) 첫 카테고리부터 시작
    return best_combination, min_waste
    코드 읽는 법 — get_min_waste(index, chosen)는 “index번째 카테고리부터 끝까지 골랐을 때의 최소 잔반량과 그 조합”을 돌려줘요. 고기에서 하나를 고르고 → 나머지(야채·국·반찬)의 최소는 자기 자신을 다시 불러 구해요. float('inf')는 무한대예요. 처음에 아주 큰 값으로 두어야 어떤 값이 와도 “더 작다”로 갱신돼요. tuple(chosen)은 리스트를 딕셔너리의 키로 쓸 수 있게 튜플로 바꾼 거예요.

    해 보기 · 우리 학교 데이터로 바꾸기

    4단계 · 프로그램 검증 및 디버깅

    프로그램이 돌아간다고 끝이 아니에요. 정말 맞는 답을 내는지 확인하고(검증), 숨어 있는 오류를 찾아 고쳐요(디버깅).

    검증 ① 입력 데이터
    재료가 올바른가
    • 모든 메뉴에 'waste' 키가 있고 값이 정수인가
    • 카테고리마다 메뉴가 하나 이상 있는가
    • 카테고리 속 메뉴가 모두 menu_data에 있는가
    검증 ② 함수
    부품이 제대로 도는가
    • 모든 카테고리를 고르면 잔반 0을 돌려주는가(종료 조건)
    • 같은 상태를 두 번 계산하지 않는가(dp)
    • 카테고리마다 정확히 하나씩, 겹치지 않게 골랐는가
    검증 ③ 출력
    답이 맞는가
    • 메뉴가 적은 작은 데이터로 돌려 보고
    • 손으로 직접 계산한 답과 비교해요

    디버깅 ① 오류 메시지 읽기. menu_data에 '소고기': {'waste': 30}을 깜빡 빼먹으면 어떻게 될까요?

    KeyError: '소고기'

    KeyError는 “그런 이름표(키)의 서랍이 없어요”라는 뜻이에요. 카테고리에는 소고기가 있는데 메뉴 데이터에는 없어서 생긴 오류예요. 오류 메시지는 무서운 것이 아니라 어디를 고쳐야 하는지 알려 주는 쪽지예요.

    디버깅 ② 테스트 케이스 추가. 새로운 메뉴를 넣어도 잘 돌아가는지 확인해요. (위의 전체 프로그램을 먼저 실행한 다음 실행하세요.)

    menu_data['오리고기'] = {'waste': 15}          # 오리고기 추가
categories['고기'] = ['닭고기', '돼지고기', '소고기', '오리고기']

best_combination, min_waste = dp_minimize_waste(menu_data, categories)
print(f"최소 잔반량 메뉴 조합: {best_combination}")
print(f"최소 잔반량: {min_waste}g")
    최소 잔반량 메뉴 조합: ['오리고기', '브로콜리', '된장국', '김치'] 최소 잔반량: 70g

    카테고리마다 메뉴 개수가 달라져도 안정적으로 답을 내요.
