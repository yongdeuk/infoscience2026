    교과서 · Ⅰ 1-1 함수의 이해

    함수의 구조

    함수는 특정한 작업을 수행하도록 작성된 독립적인 코드 블록입니다. 파이썬이 미리 준비해 둔 내장 함수(print(), sum())와, 필요에 따라 직접 만드는 사용자 정의 함수가 있습니다.

     함수명(매개 변수1, 매개 변수2, ... ):
    실행할 문장
     반환값
    구성 요소설명필수 여부
    함수명고유한 함수 이름필수
    매개 변수인수를 전달받기 위해 사용하는 변수생략 가능
    함수 본문기능을 실행하기 위한 명령어(들여쓰기로 구분)필수
    반환값처리 결과를 호출한 쪽으로 되돌려주는 값생략 가능

    교과서 · Ⅰ 연습 코드 문제

    문제 1 세 수 중 최댓값 기초 · 함수

    세 정수를 매개 변수로 받아 가장 큰 값을 반환하는 함수 max_of_three(a, b, c)를 작성하시오. 단, 내장 함수 max()는 쓰지 않는다.

    max_of_three(3, 9, 5)  →  9
max_of_three(-2, -7, -4)  →  -2
    정답과 해설

    기준값을 하나 정해 두고 나머지와 차례로 비교합니다. 첫 값을 최댓값으로 가정하는 것이 정석입니다.

    def max_of_three(a, b, c):
    biggest = a                 # 일단 a가 가장 크다고 가정
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest

print(max_of_three(3, 9, 5))       # 9
print(max_of_three(-2, -7, -4))    # -2

    빈칸

    세 수 중 최솟값

    max_of_three()를 거꾸로 바꿔 가장 작은 값을 돌려주는 min_of_three()를 완성하세요.

    def min_of_three(a, b, c):
    smallest = a
    if b ___ smallest:
        smallest = b
    if c < smallest:
        smallest = ___
    return smallest

print(min_of_three(3, 9, 5))
print(min_of_three(-2, -7, -4))
    힌트

    더 작은 값을 찾으니 비교 기호는 <예요. c가 더 작으면 smallest에 무엇을 넣어야 할까요?

    정답 코드 보기
    def min_of_three(a, b, c):
    smallest = a
    if b < smallest:
        smallest = b
    if c < smallest:
        smallest = c
    return smallest

print(min_of_three(3, 9, 5))
print(min_of_three(-2, -7, -4))
    고치기

    None이 나오는 이유

    직사각형의 넓이를 구하는 함수인데, 실행하면 숫자 대신 None이 나와요. 한 줄을 고쳐 12와 30이 나오게 하세요.

    def rect_area(w, h):
    area = w * h

print(rect_area(3, 4))
print(rect_area(5, 6))
    힌트

    함수 안에서 계산만 하고 돌려주지 않으면 부른 쪽은 아무것도(None) 받지 못해요.

    정답 코드 보기
    def rect_area(w, h):
    area = w * h
    return area

print(rect_area(3, 4))
print(rect_area(5, 6))

def max_of_four(a, b, c, d):

    힌트

    biggest = max_of_three(a, b, c)로 시작한 다음, d와 한 번만 더 비교하면 돼요.

    정답 코드 보기
    def max_of_three(a, b, c):
    biggest = a
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest

def max_of_four(a, b, c, d):
    biggest = max_of_three(a, b, c)
    if d > biggest:
        biggest = d
    return biggest

print(max_of_four(3, 9, 5, 12))
print(max_of_four(-2, -7, -4, -9))
