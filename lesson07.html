    ‘목록 안에 있는가’는 in, 값으로 지우는 리스트 메소드는 remove()예요. i번째 곡은 playlist[i]예요.

def add_song(song):

    print(f"'{song}'이(가) '{playlist_name}'에 추가되었습니다.")

def remove_song(song):
    if song in playlist:
        playlist.remove(song)
        print(f"'{song}'이(가) 삭제되었습니다.")
    else:
        print(f"'{song}'은(는) 목록에 없습니다.")

def show_playlist():

    4확인 문제

    Q1함수 안에서 playlist.append(song)은 global 없이 되는데 playlist = []는 global이 필요한 이유는?

    해설 — 대입문이 있어야 파이썬이 그 이름을 지역 변수로 봐요. 내용만 바꾸는 메소드 호출은 바깥 리스트를 그대로 써요.

    Q2기능별로 함수를 나누어 프로그램을 만들 때의 장점이 아닌 것은?

    해설 — 함수로 나누는 목적은 가독성·재사용성·유지 보수예요. 속도가 빨라지는 것과는 관계가 없어요.
