    문제 6 이진 트리의 높이 중급 · 트리

    리스트로 표현한 이진 트리(루트 인덱스 1, 빈칸은 0)에서 높이를 구하는 height(tree, i)를 재귀로 작성하시오.

    tree = [0, 'A', 'B', 'C', 'D', 0, 0, 'E']
height(tree, 1)  →  3
    정답과 해설

    “내 높이 = 왼쪽·오른쪽 자식 중 더 깊은 쪽 + 1”입니다. 인덱스가 범위를 벗어나거나 값이 0이면 높이 0입니다.

    def height(tree, i):
    if i >= len(tree) or tree[i] == 0:    # 기본 단계: 빈 노드
        return 0
    left = height(tree, i * 2)
    right = height(tree, i * 2 + 1)
    return max(left, right) + 1

tree = [0, 'A', 'B', 'C', 'D', 0, 0, 'E']
print(height(tree, 1))    # 3

    문제 7 이진 탐색 트리에 넣고 정렬해 꺼내기 심화 · 트리

    값을 이진 탐색 트리에 넣은 뒤 중위 순회(왼쪽 → 자기 → 오른쪽)로 출력하면 저절로 오름차순이 됩니다. 이를 확인하는 코드를 작성하시오.

    넣는 순서: 8, 3, 10, 1, 6, 14, 4, 7
중위 순회: 1 3 4 6 7 8 10 14
    정답과 해설

    왼쪽 서브 트리에는 작은 값만, 오른쪽에는 큰 값만 있으므로 왼쪽부터 훑으면 자동으로 정렬된 순서가 나옵니다.

    def insert(node, value):
    if node is None:
        return {'val': value, 'left': None, 'right': None}
    if value < node['val']:
        node['left'] = insert(node['left'], value)
    else:
        node['right'] = insert(node['right'], value)
    return node

def inorder(node, out):
    if node is None:
        return
    inorder(node['left'], out)    # 왼쪽
    out.append(node['val'])       # 자기
    inorder(node['right'], out)   # 오른쪽

root = None
for v in [8, 3, 10, 1, 6, 14, 4, 7]:
    root = insert(root, v)

result = []
inorder(root, result)
print(result)      # [1, 3, 4, 6, 7, 8, 10, 14]

        return 0
    left = height(tree, i * 2)
    right = height(tree, i * 2 + 1)

    def height(tree, i):
    if i >= len(tree) or tree[i] == 0:
        return 0

    right = height(tree, i * 2 + 1)
